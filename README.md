## 一、这是什么

```
三本书（《贪婪的多巴胺》/《活出生命的意义》/《自我的发展》）
→ 抽成 2921 条观点（spec/观点总表/）
→ 用代码构造一个"像人一样说话"的对话系统
→ 大模型只当"大脑"；系统的状态/规则/闸门决定这个大脑"该想什么"（乙案）
```

**用户的原话（判分的最高依据）：**
> 「我想要的就是在我的要求下成长起来的满分的模型。这就是对我的『有用』。
>  至于满分要求是什么……大概就是参照数据对心理学和生物学的抽象分析，
>  用代码构造出一个类似系统，既能像人一样进行逻辑沟通，也不能违反书籍里的思想。
>  至于怎么验证书籍的每个观点，这需要你自己整理并做并集交集整理，形成逻辑闭环。
>  最后再喂回系统里。」
