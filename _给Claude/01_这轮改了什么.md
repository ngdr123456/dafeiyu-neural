## 一、四处改动

### ① `think.py` + `pipeline.py` + `engine/stance.py` —— 给大脑具体支点

**病灶（Gemini 第三封发现，我独立核实）：**

```
`_pick_anchor`（respond.py）与 `_pick_concrete`（render.py）这两个
"从用户原话里逐字抠出具体物"的算子，**只被 renderer 路径调用**；
而 renderer 在训练中从不执行（`train.py:330 use_render=False` + `pipeline.py:632 elif` 双保险）。
⇒ 她从来没拿到过具体支点，只有抽象标记 + 一串读数。
用户说短话、又没命中抽象观念词表时，`observations` 是"（没听出什么）"
⇒ 她手里除了原话什么都没有 ⇒ 只能把它换个语序还回去 = 回声。
```

**改法：**

```
Frame 新增三栏：anchor（具体锚点）/ concrete（具体画面）/ stance（行动姿态），
紧挨【他刚才说的】放进简报。
stance 由新建的 engine/stance.py 把 10 个机制相位确定性地翻成一句姿态。
FRAME_SYSTEM 第 6 条改写为「说短，抓具体，不复述整句」。
```

**测试**：`test_frame_anchors.py` F1–F6（6/6）

### ② `pipeline.py` —— META 收窄（机制层通电）

**病灶：**

```
有 mech 的 24 行里 20 行（83%）planned=META_REPLY、_carried=True、
phase 全 NO_TENSION、**w 全部 9.4**（24 行同一个值）⇒ 死快照。
根因：pipeline.py:362 的 META 分支在 mech.step()（436 行）**之前**就 return 了。
     而家教说话带「你说…」「你想过没有…」这类口头禅，一看到问号就判 META。
```

**改法：**

```
intent=="META" 时先收窄：
  · 显式问系统（什么模型/你是谁/在哪跑/…）⇒ 照旧 META
  · 否则输入 ≥20 字、或有生活锚点、或命中心理标记 ⇒ 归还主干道
依据（实测）：被误判 META 的 11 行输入长度 min=28 / 中位 42；
             输入 <15 字的 22 行里 META_REPLY **0 行** ⇒ 长度判据能分开。
```

**测试**：`test_meta_narrowing.py` M1–M7（7/7）｜变异 3/3

### ③ `action_observation.py` —— 三个动作的纯字面识别

```
· QUESTION 放宽：从"全文不许有句号"改为"以问号结尾且 ≤60 字"
  ⇒ 「我没说听天由命。你眼下那堆烂摊子，是什么？」现在算 QUESTION
· 新增 REPORT_OWN_STATE：含"我这边/我没有/我不知道/我答不了…"
· 新增 ACKNOWLEDGE：≤20 字、无问号、**引号里的字必须逐字出现在用户原话里**、
  引号外与原文最长公共子串 <4 字
```

**★ 第三条我**收紧**了 Gemini 的原判据 —— 他的"无引号时 4-gram 重合=0"方向反了：**

```
输出「你爸一定又骂你了，你从小就怕他。」（纯编造，16 字）raw = 「我爸昨天来了。」
  长度 ✓  无问号 ✓  最长公共子串 1 字 < 4 ✓  ⇒ **编造恰好满足"重合低"**
⇒ 改成：必须带引号，且引号内的字逐字在原话里。代价是覆盖率低，但「不许编」优先。
```

**测试**：`test_action_recognition.py` O1–O9 + O5b/O5c/O6b（13/13）｜变异 4/4

## 二、顺带修掉两个"会让她更糟"的问题

```
① respond.py `_pick_anchor`：
   `_ANCHOR_THING` 有单字项（钱/车/病/学），于是"毛病"里切出"病"、"同学"里切出"学"。
   接进 Frame 后模型会问「你说的「病」是怎么回事」——比复述更糟：**引用一个对方没说过的词**。
   ⇒ 加"单字必须独立出现"守卫（前面是句首/标点或带人称代词）。

② render.py `_pick_concrete`：
   没有体验词时退回**最长小句**（常常≈整句）。
   塞进【具体画面】等于**教她复述**。
   ⇒ 注入处加 60% 长度守卫，宁可空着，也不给一个假的支点。

③ respond.py `_pick_anchor`（问题 2 的那处）：
   加**地点模式**（[地点]{1,2}(楼|栋)[序数]{1,2}(层|楼) 等），
   并把"同类内取最长"扩成"跨类取最长"，让具体物「北楼三层」（4 字）
   胜过抽象词「项目」（2 字）。
```
