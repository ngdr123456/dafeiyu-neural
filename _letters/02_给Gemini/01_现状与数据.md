## 一、系统在做什么（三十秒）

```
用户说话
 → 标记层：命中十几个标记（immutable / over_intention / attitude_clause / cliche …）
 → 阶梯（行为库）：按标记选一个"言语行为"
        opposed_pair → 并排呈现
        immutable    → 区分能改与不能改
        over_intention → **只许复述或问"非得不可吗"**
        cliche       → 要求具体
        其余情形      → **复述** ← 兜底
 → 机制层：算一堆数（想要/喜欢/张力/结构压力），**不产生任何文字**
 → 回应层：从模板组装，或让模型生成后过三道闸门
 → 台账：追加式记录
```

**两条硬纪律：**

```
① 不许编：模型生成的话必须逐字可溯，编造即退回模板
② 不许评价、不许助推（尤其"过度意向"：不许说任何推动他更想要的话）
```

## 二、真正的生成路径只有一条：**FRAME_SYSTEM**

**这是本轮最重要的结构发现，而且是我先弄错、后来查代码才发现的。**

```python
# train.py:330   use_render: bool = False      ← 训练默认不开渲染层
# train.py:770   use_think=not a.offline        ← 训练默认开思考层
# pipeline.py:624-632
if self.thinker is not None:
    response_mode = "brain"      # ← FRAME_SYSTEM
elif self.renderer is not None:
    response_mode = "render"     # ← RENDER_SYSTEM；**elif**，thinker 在时永不执行
```

**⇒ `RENDER_SYSTEM`（含"不要遗漏，材料里有几件事就说几件"）**在训练里从未执行**。**

**⇒ 唯一生效的生成 prompt 是 `FRAME_SYSTEM`，它的关键条目：**

```
6. **说短**。一到三句。不要总结，不要排比，不要分点。
7. 如果这一刻确实没什么可说，**沉默是被允许的**。
```

## 三、评审（judge）的情况

**评审 prompt（`admin_agent.py:79 JUDGE_SYSTEM`）的关键一句：**

```
「【它的回应】—— 你看到的。这是意见，是线索，**不是依据**。
  【它的内部读数】—— 你知道的。**这才是依据**。」
```

**★ 但它给出的问题类别里有 `mechanical`（太机械、像模板、像复读）——**
**这件事只能**从回应看出来**，读数里没有任何一项能表达它。**

**评审看到的读数只有 7 个：**
```
想要 Hz｜喜欢｜敏化｜结构误差｜张力/10｜相位｜指向
```

## 四、我用 635 次调用查了这个标签（关键数据）

### ① 标签自身噪声：**三遍只有 56% 一致**

```
215 行 × 3 遍（同一输入、同一设置、都 text-only）
  三遍全一致 **120（56%）**
  2:1 多数    79（37%）
  1:1:1 平票  16（ 7%）
```

**⇒ 按事先写好的判据（不一致 ≥25% 即噪声太大）：**成立**。**

### ② 读数把 `mechanical` 稀释了三倍

```
原判定（带读数）    mechanical  **9.3%**（20/215）
text-only（去读数） mechanical **27.9%**（60/215，三遍多数投票）
```

**⇒ 读数的方向是**单向**的：它让评审**更宽容**。
**⇒ `mechanical` 在去读数后仍保留 80% ⇒ 它**不是**读数的回显，但**被读数稀释**。**

### ③ 所有文本信号的四列实测（去噪标签，基准率 27.9%）

```
信号                      mech侧  none侧   精度    提升     判定
**新词占比 ≤0.30**         43%    18%     60%   **2.03×  可用**（阳性 46）
复制率 ≥0.60              28%     1%     94%    3.38×  线索（阳性 18）
复制率 ≥0.80               7%     1%     80%    2.87×  线索（阳性 5）
结构化词                   12%    11%     39%    1.39×  线索（阳性 18）
用户话 ≥60 字               7%    19%     18%    0.65×  线索（阳性 22）
被问轮                     18%    51%     18%    0.66×  无区分
用户话 ≥40 字               35%    59%     27%    0.96×  无区分
情感句被漏（<0.40）           12%    38%     16%    0.58×  无区分
复制率 ≤0.40（改写）          37%    92%     20%    0.72×  无区分
```

**「新词占比」定义**：输出里不在用户当轮原话中的字的比例（按字计）。

### ④ 长度效应**反转**

```
                 <40 字   40–60 字   >60 字
原始标签（带读数）    6%  →    10%  →   **22%**   ↑
去噪标签（text-only）**35%** →  22%  →    13%     ↓ **相反**
```

**⇒ 同一个量、同一批数据，两种标签下方向相反。**
**⇒ 所以"用户话越长越机械"在去噪标签下**不成立**。**

## 五、一个反例：为什么"复制率高"不等于错

**复制率 0.93、但判为 `none`（没问题）的那一条：**

```
他：……你把刚才那个题目**再念一遍**给我听，就那句"即使结果是这样，我也不后悔"，
    **我想再听一遍**。
她：即使结果是这样，我也不后悔。
```

**⇒ 他**明确要求复述** ⇒ 照抄是**完全正确**的。**

**而 17 条被判 `mechanical` 的，全是他只是**陈述**、她**自己选择**复述：**

```
他：可我一想起每天走同一条路上班，就觉得这辈子好像已经看到头了。
她：你妈念叨的是…你说的是…两句都在。          ← 他自己没说"你复述一下"

他：……我低头说了句"随便"，她就真去做了。
她：一天里能坐一块儿的就那一会儿。你说了"随便"，她真去做了。
```

**★★ 所以判据可能是「这次复述是不是他要求的」。**
**但我测了：这种"被要求复述"的轮次只有 **3/215 = 1.4%**，加进信号里提升几乎不变（2.07× vs 2.03×）⇒ **频率太低，不能当判据**。**

## 六、这个项目能做到的"可本地确认"只有一件事

```
`self_goal.literal_check`：
  在她输出里找「」引号片段，逐段比对"目标要求的证据"是否**逐字出现**
  ⇒ 全中 ⇒ 记为 QUOTE_SOURCE_SET_CONFIRMED（唯一在自由生成路径上被确认的动作）
```

**⇒ 也就是说：**凡是需要"理解她说了什么"的判断，我们都做不到独立确认。**
**我们自己的 `content_fidelity.py` 头注释写着：**

> 「This is a correlated model opinion, never independent semantic proof」

## 七、用户的硬约束（会影响可行方案）

```
① 不许编（逐字可溯，编造即退回模板）
② 不许评价、不许助推
③ 不许为指标好看而收紧/放宽判据
④ 改动先报后动
⑤ ⚠️ 用户**没有时间做一对一训练**（原话："我没时间给它一对一训练"）
```

**⇒ 所以"靠人看效果慢慢调"这条路是关着的。**
