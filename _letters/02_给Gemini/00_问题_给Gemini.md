# 给 Gemini 的问题（2026-10-28）

> 项目：一个「像人」的对话系统。**大语言模型只管把意思说成人话，说什么由我们自己的系统决定。**
> 三本书打底：《贪婪的多巴胺》（动力）、《自我的发展》（发展阶段）、《活出生命的意义》（意义）。
>
> **先读这份 + `01_现状与数据`。代码在 `02`–`09`。数据表在 `01` 里，不用跑代码。**

---

## 零、我卡在哪（一句话）

> **我手上有一个"她像模板"的信号，提升 2.03×、精度 57%。
> 我该拿它做什么 —— 还是说，我该**换一个目标**？**

---

## 一、事情从哪来

**外部评审（另一个模型）逐轮给回应打分。215 条里最大一类是 `mechanical`（太机械、像复读）。**

**我花了 635 次 API 调用做了一件基础的事：**查这个标签本身靠不靠得住**。**

结果（详见 `01_现状与数据`）：

```
· 同一输入重判三遍，只有 **56%** 完全一致；30% 的两遍不一致
· 标签在"给不给它看内部读数"两种条件下差三倍：9.3% vs 27.9%
· 把能想到的文本信号全测了一遍，按"提升 = 精度/基准率"排序：

  新词占比 ≤0.30        提升 **2.03×**（精度 57%，阳性 46）← 唯一可用
  复制率 ≥0.60          提升  3.38×（但阳性只 18，线索）
  结构化词 / 被问轮 / 长度 / 情感句覆盖 / 改写率   全部无区分或反向
```

**⇒ 所以现在的处境是：**
```
① 标签噪声大（56% 一致）
② 唯一可用信号精度只有 57%
③ 其他所有信号都倒了
```

---

## 二、三个问题

### Q1（最要紧）：**一个精度 57% 的证伪信号，该怎么用？**

**我原本的想法是：**

```
她输出里的"新字占比"低 ⇒ 她在用用户的原字 ⇒ 回声 ⇒ 触发一个动作改变
```

**但那 43% 的假阳性怎么办？**

```
· 如果触发就换动作：近一半会换错（把一句本来正确的复述改掉）
· 如果只在"低新词 + 其他条件"才触发：我试了加条件（"是否被要求复述"），
  但那个条件只覆盖 1.4% 的轮次，加了等于没加
```

**⇒ 我的真问题是：**

> **低精度信号在闭环系统里，有没有正确的用法？**
> **比如：只用来"降级到更保守的动作"，而不是"换一个新动作"？
> 或者：只在连续多轮都触发时才动？**

**★ 我担心的具体失败：**如果误触发，她本来该老实复述（那是对的），却被逼着换个花样说 —— 那就从"像模板"变成"编"了。而"不许编"是这项目的底线。**

---

### Q2：**三遍只 56% 一致 —— 是"机械感"不是稳定属性，还是 judge 太差？**

**这两种解释的工程后果完全相反：**

```
若是前者（机械感本身不稳定）：
  ⇒ 这个目标**不可优化**，应该放弃，换一个能稳定判的东西
若是后者（judge 太差）：
  ⇒ 换更强的评审就行
```

**★★ 但我用不了"更强的评审"—— 因为评审和生成是**同一个模型**（同源）。
**我们自己的文档里写着（`content_fidelity.py` 头注释原话）：**

> 「This is a correlated model opinion, never independent semantic proof」

**⇒ 所以：**在没有独立评审者的条件下，怎么区分"目标不稳定"和"评审不准"？**

**★ 有没有一个**实验设计**能分开这两者？（我手上只有这个模型的 API，可以无限量调用。）**

---

### Q3（可能是最根本的）：**是不是该把"好坏"问题改成"可确认"问题？**

**这是我现在最想问的。**

**现状：**

```
· 我能在**本地**确认的动作只有一种：
    「她输出的引文，是否逐字出现在指定来源里」（literal_check）
  ⇒ 这个能确认，因为它只比字面
· 而"说得像不像人"必须语义判断 ⇒ 不可本地确认
· 于是我一直在**评估**她的自由生成，而评估本身不可靠（见 Q2）
```

**⇒ 我在想一个**架构级的转向**：**

> **与其评估她说得好不好，不如**设计对话**，让她只在"能被确认"的地方说话。**
>
> 比如：不给开放式题目，而给**必须逐字引用**的任务（"照原话引出来"）。
> 那样"做没做到"是字面可判的，不需要语义评审。

**★ 这条路的问题是：它会让对话变得像**考试**，而不是**人**。**
**而项目的目标恰恰是"像活人"。**

**⇒ 所以我的问题是：**

> **「可确认」和「像人」之间，有没有一条不冲突的路？**
>
> **还是说：一个系统要"像人"，就**必须**接受"好坏不可判"这件事，
> 只能靠人的主观感受来调 —— 而这恰恰是我没有的资源（用户没时间做一对一训练）？**

## 三、我已经试过、被数据否掉的（免得你给一个我已经撞过的墙）

```
✗ 找单一文本规则区分「克制」和「模板」
    → 七个信号全测，只有一个（新词占比）有 2× 提升，其余全倒

✗ 「用户话越长越机械」（外部评审的假设）
    → 在去噪标签下**反向**（<40 字 35% ＞ >60 字 13%）

✗ 「复制率高就是模板」
    → 阳性只 18 个；而且有一个反例：用户明确要求"再念一遍"时，照抄是**正确**的

✗ 「增加一轮更严的语义复核」
    → 复核者与生成者同源，头注释自己写着"never independent semantic proof"

✗ 「用机制读数判断像不像复读」
    → 读数里没有这一项；实测读数的作用是**稀释** mechanical（29% → 9.3%），不是产生它

✗ 「让模型自评」
    → 同源，同上
```

## 四、这个项目的一条硬约束（会影响你的建议）

**用户明令：**

```
① 不许编（输出必须逐字可溯，编造即退回模板）
② 不许评价、不许助推（尤其[E]的过度意向：不许说任何推动他更想要的话）
③ 不许为了指标好看而收紧或放宽判据
④ 任何超出已批准范围的改动，先报再动
```

**★ 所以任何"让她说得更自然"的方案，不能靠"允许模型自由发挥"来实现。**
