## 一、真凶 1（为什么算子/回想/连锁触发率全卡死？）：汉语口语的「零形回指（省略宾语）」被你的 `subject` 全等匹配一刀切死了！

你在第四节诊断说：
> `② 12 轮里只抽出一次 "FIXED + ACTION 同轮且 subject 匹配"`
> `④ 空档回想需要 subject 匹配，而 12 轮里 subject 很少撞上。`

**请你立刻看一眼这 12 轮（以及之前我们夸过的那几条黄金样本）抽出来的 `Claim`！为什么 `subject` 撞不上？**
因为在真实的汉语口语里：
* 当一个人第 1 句（或第 1 轮）说处境/愿望时，会带出主语/宾语名词（如 `WANT_MUST: 「想跟她把话说清楚」` → `subject="她"`；或 `FIXED: 「那版方案还是被打回来了」` → `subject="方案"`）；
* 但紧接着他说自己的**应对或代价（`ACTION` / `COST_FEEL`）**时，**汉语口语 90% 都会省略主宾语（零形回指 Zero Anaphora）**！
  你看你自己贴出来的真实句子：
  * `「到嗓子眼儿又咽回去」`（`subject = ""`！）
  * `「不敢点开」`（`subject = ""`！）
  * `「没敢说」`（`subject = ""`！）
  * `「把最该说的话咽下去」`（`subject = ""`！）
  * `「手指已经抬起来了，又放下」`（`subject = ""`！）
  * `「饭都不想吃」`（`subject = ""`！）

**你想想看：**
在同一个会话里，用户上一轮（或前半句）刚说了 `subject="她"` 或 `"方案"`，下一轮（或后半句）接着说 `「到嗓子眼儿又咽回去」`（`subject=""`）。
在人脑子里，这两句话 100% 是在讲同一件事！
可在你的代码里，因为你要求 `c1.subject == c2.subject`（且非空），`"她" != ""`、`"方案" != ""`，**于是 90% 真正的同轮和跨轮人类张力，全被 `subject` 字符串不等给拦在了门外！**

### ★ 破局改法（不降抽取精度，只加 8 行「汉语零形回指兼容函数 `_subject_compatible`」）：
在 `cognition_ops.py` 里，把死板的 `c1.subject == c2.subject` 替换为按轮次距离分层的 **`_subject_compatible(c1, c2, same_session: bool)`**：

```python
def _subject_compatible(c1: Claim, c2: Claim, *, same_session: bool = True) -> bool:
    s1 = (c1.subject or "").strip()
    s2 = (c2.subject or "").strip()
    dist = abs(c1.turn - c2.turn)
    # 1. 若两边都抽出了明确的不同实词对象（如一边是“我妈”，一边是“方案”），且不是代词指代，直接判不兼容！
    _PRON = {"他", "她", "它", "那", "这", "对方"}
    if s1 and s2 and s1 != s2 and not (s1 in s2 or s2 in s1) and not (s1 in _PRON or s2 in _PRON):
        return False
    # 2. 同轮内（dist == 0）：同一个人同一口气说的半句话，只要两边 subject 不冲突（有一边省略为空或相等），天然兼容！
    if dist == 0:
        return True
    # 3. 同一会话紧邻 1～2 轮内（dist <= 2）：汉语口语天然省略主宾语（零形回指）
    #    只要：① s1 == s2（非空相等），或 ② 一方非空而另一方省略为空（s1 == "" or s2 == ""），或 ③ 代词回指，即兼容！
    if same_session and dist <= 2:
        return bool(s1 == s2 or not s1 or not s2 or (s1 in _PRON) or (s2 in _PRON))
    # 4. 跨 3 轮以上远距离（dist >= 3）：必须两边都有明确非空且匹配的 subject 才允许跨远轮配对（严防远距离乱凑）
    return bool(s1 and s2 and (s1 == s2 or s1 in s2 or s2 in s1))
```

**你看这 15 行代码的威力：**
* 如果一边说的是 `"我妈"`，另一边说的是 `"方案"`（两个不同的非空实词），第 1 条直接拦截，**绝不乱凑**！
* 如果隔了 3 轮以上（`dist >= 3`），第 4 条依然要求非空 `subject` 严格匹配，**绝不翻远年旧账乱配**！
* **但在同一句话里（`dist == 0`）或同一场对话紧挨着的 1～2 轮里（`dist <= 2`）**，当他说完 `"想跟她说清楚"`（`s1="她"`），下一句说 `"到嗓子眼又咽回去"`（`s2=""`）时，系统立刻知道这两句是在讲同一件事！
