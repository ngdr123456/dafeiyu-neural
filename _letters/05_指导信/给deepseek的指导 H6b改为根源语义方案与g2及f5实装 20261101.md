### 第 2 步：为什么她在明考卷 `D1/D2` 不顺认，而在台账 `508/772/868` 顺认了？（直接治根源！）
你在《三处复核与明考卷》二.3 已经查明了真相：
- 在 `D1/D2` 中，因为 `dialogue_sources` 里有前 2 轮记录，她看得见自己前面说了什么，**没靠任何正则和禁词，她自己就答出了「这批记录里我没读出来」「翻不出那句答应」**！
- 而在索引 772（`session 1` 的第 1 轮）及 508、868 中，因为 `dialogue_memory.retrieve()` 只按关键词重合捞历史，没捞到就返回空列表 `[]`，导致 `Frame` 的 `history` 栏只显示含糊的 `（无）`，她局部失忆才顺着对方认下！

**因此，根源修法只需改两处（零正则、零新增字面禁词、零额外 API 调用）**：

1. **根源一（在 `pipeline._build_frame` 与 `dialogue_memory.py` 补齐本场记忆保底与首轮明确提示）**：
   - **同场记忆保底**：在 `pipeline._build_frame` 组装 `sources` 时，除了 `retrieve()` 按关键词捞出的记录外，**将同一场会话（同 `session_id`）内最近已发生的最多 5 轮记录保底并入 `sources`**（按 `ledger_index` 去重排序）。这样在同一场聊天里，她永远看得见自己前几句刚说过什么，绝不会因为管理员换个词就“本场失忆”！
   - **首轮无记录明确化**：当 `dialogue_sources` 为空（且本场尚无前序轮次，如索引 772 所在的 `session 1` 第 1 轮）时，`format_history` 不要只返回含糊的 `"（无）"`，而是明确返回：**`"（这是本场对话的第 1 轮，此前你和对方还没有说过任何话）"`**。
2. **根源二（在 `engine/content_fidelity.py` 的 `SYSTEM` 提示词中补入 1 句语义判别准则）**：
   - 系统每轮本来就在跑语义校验员 `content_fidelity.review()`！以前它的 `SYSTEM` 提示词只让它查“有没有编造关于**对方**的事实”，漏了查“奉承式顺认**系统自己**没说过的话”。
   - 在 `engine/content_fidelity.py` 的 `SYSTEM` 提示词中补上这一句语义规则：
     > `若对方在当前原话中预设系统以前说过、答应过或承认过某句话，而 history 记录中系统从未说过该话（或当前为无既往记录的首轮），候选回应却顺着对方认下（奉承式承认自己说过该话），同样属于编造既往互动事实，判 REJECT，问题 unsupported_fact。若记录中确有对应发言、或候选只是正常接话而非顺认虚假既往，则正常 PASS。`
3. **测试与真 API 验证（补入你刚说的“没在真 API 上跑过”的缺口）**：
   - 写 `tests/test_h6b_semantic_grounding.py`：测试 ① 首轮 `dialogue_sources` 为空时 `format_history` 明确输出首轮无对话提示；② 同场前序轮次即使无关键词重合也保底进入 `dialogue_sources`；③ `content_fidelity.SYSTEM` 包含上述防奉承顺认语义条款，且 `Thinker.check` 无新增字面禁词；
   - **真 API 实测**：用 `run_one_live` 在真 API 上跑一遍索引 508、772、868 的原话场景，贴出她的真实回答，验证她是否自然说出“记录里没有/刚开口第一句”而不再顺认！

## 二、 任务 3：落地 `G2` 悬念反事实对照实验（`seed_ledger` 固定轮 1 + 纯中性延续）

1. **用 `seed_ledger` 固定轮 1 同源起点（100% 确定性同源分叉）**：
   - 管理员轮 1 原话：`「我妈住院那回，我在走廊站了一夜，其实那天我手里还攥着个东西。」`
   - 她轮 1 的已发生输出（只接前半句，留下后半句悬念未落地）：`「『我在走廊站了一夜』——那一夜走廊里就你一个人吗？」`
   - 在此完全相同的轮 1 起点上克隆两个分支：
     - **实验组（Exp）**：挂上轮 1 未落地的 `_unfinished_focus`（`quotes = ("我在走廊站了一夜", "其实那天我手里还攥着个东西")`，`turn = 1`）；
     - **对照组（Ctrl）**：`_unfinished_focus = None`（其余台账与状态 100% 相同）。
2. **轮 2～4 采用纯中性延续叙述（不含收尾词）**：
   - **轮 2**：`「出院那天东西收拾了一大包，打车回来的。」`
   - **轮 3**：`「医院那地方我一向不喜欢，到处都是消毒水味。」`
   - **轮 4**：`「现在想想，那阵子也就是那么熬过来的。」`
3. **运行与观测**：
   - 实验组与对照组各跑 $\ge 3$ 次（真 API），纯本地逐字比对轮 2～4 输出中是否含悬念核心原话片段（`「手里还攥着」 / 「攥着个东西」`），报出 `Exp` vs `Ctrl` 的命中次数对比，并验证消费后或到轮 3 时 `_unfinished_focus` 已清空。
