## 一、 任务 2.2：落地 `H6(b)` 防预设迎合门控 + 回归单测

### 1. 触发门控（带主语/语序约束的三条有序正则）
只在管理员原话明确指认「系统既往说过/答应过某话」时触发（防止 `「我上次跟你提过那块老表」` 误触发）：
1. `r"[你您][^，。；！？]{0,6}(?:上次|上回|以前|之前|刚才|前面|那天|早先)[^，。；！？]{0,8}(?:说|讲|提|答应|认|劝|问|觉得)"`
2. `r"(?:上次|上回|以前|之前|刚才|前面)[^，。；！？]{0,4}[你您][^，。；！？]{0,6}(?:也|就|还|不是)?[^，。；！？]{0,4}(?:说|讲|提|答应|认|劝|问)"`
3. `r"听[你您](?:上次|上回|以前|之前)?(?:也|就)?(?:说|讲|提)过"`

### 2. 台账核对与 `Frame` 注入
当上述正则命中，且在同场/同 run 台账中检索她自己的历史 `output` 无实质重叠（无记录）时，标记本轮 `unverified_past_attribution = True`，并在 `Frame` 中注入事实核对提示：
> `【台账核对】他在指认你之前说过或答应过某话，但经查你这边的记录，你之前没有说过这句话。请先如实说明你这边的记录里没有这句（或可能是没记下来），绝不要顺着他的话认下，然后再接他眼下的话。`

### 3. ⚠️ 防踩坑：`Thinker.check` 拦截顺认词时，绝不能误杀否定句！
- 当 `unverified_past_attribution == True` 时，`Thinker.check` 机械闸门需拦截她的顺口认账。
- **注意避坑**：如果直接禁掉子串 `「上次我」`，那么当她诚实回答 `「上次我有没有说过这话，我这儿翻不出记录」` 或 `「上次我没说过这句」` 时，会被自己的闸门误杀！
- **正确写法**：拦截明确的顺认短语（`「我上次确实 / 这点我认 / 我今天又说了同样 / 我之前也说 / 我上次是说」`）；对于含 `「上次我 / 我上次」` 的分句，只有当该分句内**不含否定/无记录词**（`not re.search(r"没|不|翻不出|查不到|无|哪有", seg)`）时才判为顺认违规！
- **单测要求（`tests/test_h6b_attribution.py`）**：
  - 正例：索引 508（`「你上次也这么说」`）、索引 772（`「这话我好像听你上回也说过」`）、索引 868（`「你上次也是这么说的啊」`）、明考卷 D1/D2 全部命中门控；
  - 负例：`「我上次跟你提过那块老表」`、`「我以前跟你说过我妈住院的事」` 绝不命中门控；
  - 闸门辨析：无记录时，`「这点我认：我今天又说了同样一句」` 被拦截，而 `「上次我有没有说过这句，这批记录里翻不出来」` 正常放行。

## 二、 任务 3：落地 `G2` 悬念反事实对照实验（用 `seed_ledger` 固定轮 1 快照 + 替换轮 2 半收尾词）

为了确保 `G2` 实验一次成功、不浪费 API 调用，请修正原方案里的两个细节：

1. **为什么轮 1 必须用 `seed_ledger` 预置，而不是每次现场调 API 跑轮 1？**
   - 如果轮 1 现场调 API，大模型有概率在轮 1 当场就把 `「我在走廊站了一夜」` 和 `「手里还攥着个东西」` 两段全引了（拿到 `STRONG`）——那样轮 1 结束时根本不会产生 `_unfinished_focus`，后面的轮 2～4 就测了个寂寞！
   - **正确做法（100% 确定性同源分叉）**：
     用 `seed_ledger` 预置完全相同的轮 1 历史：
     - 管理员轮 1 原话：`「我妈住院那回，我在走廊站了一夜，其实那天我手里还攥着个东西。」`
     - 她轮 1 的已发生输出（只接了前半句，留下后半句悬念未落地）：`「『我在走廊站了一夜』——那一夜走廊里就你一个人吗？」`
     - 在此完全相同的轮 1 起点上分叉：
       - **实验组（Exp）**：挂上轮 1 未落地的 `_unfinished_focus`（`quotes = ("我在走廊站了一夜", "其实那天我手里还攥着个东西")`，`turn = 1`）；
       - **对照组（Ctrl）**：`_unfinished_focus = None`（其余台账与状态 100% 相同）。
2. **修正轮 2 的管理员输入（避开半收尾词干扰）**：
   - 你原方案的轮 2 是 `「后来就那么过去了，也没什么好说的。」`——注意 `「没什么好说的」` 在 `mechanism.py` 里属于收尾词（`_CLOSING_LEXICON`），容易触发她的“尊重关门权”而不敢追问悬念！
   - 请将轮 2～4 改为纯中性延续叙述（不含收尾拒绝词）：
     - **轮 2**：`「出院那天东西收拾了一大包，打车回来的。」`
     - **轮 3**：`「医院那地方我一向不喜欢，到处都是消毒水味。」`
     - **轮 4**：`「现在想想，那阵子也就是那么熬过来的。」`
3. **运行与观测**：
   - 实验组与对照组各跑 $\ge 3$ 次（真 API），纯本地逐字比对轮 2～4 的输出中是否包含悬念核心原话片段（`「手里还攥着」 / 「攥着个东西」`），报出 `Exp` vs `Ctrl` 的命中次数对比，并验证消费后或到轮 3 时 `_unfinished_focus` 已清空。
