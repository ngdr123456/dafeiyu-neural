# 关系学习接入对话：从接口到运行闭环

承接用户“我同意新变更”“继续自主工作”与“continue”的授权，本轮把前轮关系学习接口接入 Pipeline。当前范围是 blame_external（责备外指）的语言关系，不扩展到全部标记，也不增加发展计数。

## 回查原文与前后联系

回查 books 的《贪婪的多巴胺》清洗原文“新的硅霸主”（全文第545行）：作者在进化计算语境谈程序根据目标成功程度调整，成功电路加强、失败电路削弱。这给“任务预测—实际反馈—保留或修订”的软件实现提供书内依据，不能把观察者确认直接叫作生物多巴胺测量。

回查《自我的发展》p77（全文第679行）：新的原则支配部分之间联系，同时整合有用材料，保证相继组织基本连续；阶段逐步整合。p80（全文第696–699行）又区分逻辑类别理解与人格构成。因此本轮既让观察关系改变，也保留旧的纯规则、显式反例与感知权限，不把一种语言能力等同人格阶段。

M 的不接管价值评判边界沿用 M-426/M-429：第二评定人判断的是谁在断言、否定、引用或禁止言说，不能把关系标签当作用户人生价值。新规则只影响材料进入议程的条件；模型作为大脑的表达职责不改。

原文、观点表、工程实现各自保留层级。3+2 验证参数仍是 ENG；测试原文不同不保证语义独立。同一个 API 第二评定人可以作为候选之外的纠正来源，但不是第三方临床真值，也不满足 S/B 独立采样的全部要求。

## 已接通的运行路径

1. 纯规则照常解析；既有 API 第二评定人在同一请求中可额外返回 `relations`：标记、每次出现的起止位置、原文短语和封闭关系标签。不给它看学习器的预测，避免照抄候选来自证。没有新增 API 请求，也不把模型自由文字交给对话输出。
2. 校验关系证据：位置必须是整数，严格对应原文，并是已有触发短语；未知标记、伪造短语、同一位置互相冲突的关系结论丢弃。只接收 blame_external；字段缺省时保持旧接口兼容。
3. 有效的明确关系反馈经前轮学习器形成、后续验证、固化、修订和退出，落在当前台账相邻的 `relation_rules.json`。UNKNOWN 不算确认，也不算反驳；API 沉默或失败不产生学习证据。
4. 本轮反馈若反驳旧关系，先撤回旧规则，再计算本轮影响。所有已找到的触发短语每一次出现都已有固化的否定／禁止言说／引用关系，且当前 API 没有主张该标记，才可排除这个误判标记。任一次仍未知或肯定，都不能被其他片段一并否决。
5. 固化关系跨会话读取；即使新会话没有 API，也能用已有历史关系。当前 API 沉默并不构成新的否决，生效依据是历史明确反馈和后续验证。固化 ASSERTED 只表明语言关系，不自动新增一个原系统没认出的标记，仍须其他标记判据。
6. 排除标记后同步命中列表、未判定状态、责任归属签名和键，避免“标记撤了，签名还说外指”。原始评定人比对仍保留，关系层的实际影响另记。

台账 notes 中的 `关系学习=` JSON 保存每次出现的逐字位置、学习前后关系、反馈事件、是否排除以及 development_credit=0。原文仍由既有 raw_input 保存；详细历史和反馈保存在关系记忆。关系记忆不清零、不覆盖原台账，也不写入主观意义分数。

## 本轮额外修复的接线边界

之前规则评定人有 A1 门控，API 的候选列表却仍含全部标记。本轮同步过滤发送给 API 的列表，并在合并处再次过滤，防止 API 绕过系统当前可见范围。关闭感知门控的诊断模式维持原有全列表，不改开关默认值。

关系表示升为 v2：加入否定线索后是否已经结束句子、与触发片段的距离档位。这是工程观测特征，不是直接固定关系结论；可避免上一句的禁令与本句新断言落入相同条件键。原 v1 历史保留，新键重新验证，不能冒用旧关系的资格。

关系规则与导致它的反馈现在一次原子保存，避免先落已启用规则、后补理由的断点。保存失败时内存回到原快照；对话记降级原因并保留原评定结果，不因新增学习器中断原有判断流程。

## 真实管线验收与局限

临时副本的 Pipeline 接入模拟第二评定人，实际处理五条不同项目输入 `不要说了，都是他们害了项目…`；新实例没有 API 时处理另一份工作，原实现命中的责备外指标记由已固化关系排除，台账记实际影响。第二评定人给出明确相反关系时，旧关系本轮撤下，原标记保留。当前信任基线仍 I-3 / 有效平衡化 0。

这是实际运行代码的闭环测试，**反馈与句子都是构造的**，不是现实用户已验证的语言改善。不能据此声称整体对话质量、全部语言关系或阶段发展已经完成。真实反馈来源以后是正常运行中已有理解请求；本轮未调用真实 API、未开始正式训练，也没有往真实记忆填入测试关系。

28 个回归脚本在门控0/1共56次通过，5项变异被捕获。新增7项管线测试覆盖持久化、当前反驳、未知片段、逐字证据、权限列表、跨句距离、禁止从关系标签直接新增标记和写盘降级；关系学习测试新增保存失败回滚。验收副本禁止网络连接；36个真实状态文件哈希与清单未变。原有 ResourceWarning 仍在，未扩展范围修理。
