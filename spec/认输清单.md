# 认输清单（可填写对账表）

> **这份文件的目的不是证明模型对，而是规定它在什么条件下必须改自己。**
>
> [E]：**"如果没有办法改变理论以反应数据，则一个人简直难以称自己是一位科学家。"**
> [E]：**"充其量这些是科学范式方面的差异，它们无法由进一步的研究来解决，因为不同范式的支持者承认不同的数据。"**
>
> 因此本表每一行都必须能回答一个问题：**若被推翻，删掉哪条规则？**
> 答不出"删哪条"的行，是装饰，应当删除。

---

## 填写规则（三条，不可省）

1. **"数据不足"是合法且诚实的结论。** 不允许用印象补空。
2. **判定必须在看到数据之前写下标准。** 事后改标准 = 自证。
3. **每行的"若推翻则删"必须指向具体文件与具体键**（如 `rules/markers.json → markers[group_sanction]`），不能写"再研究"。

## §1 一致性预测

**预测原文**：L2↔L3 区段（遵奉↔公正）的判定与自我观察一致性最高。

**为什么这么预测**
> [E]：**"由于从遵奉到公正阶段的过渡对我们社会的成年人来说也许是一个形态的水平，因此这种过渡是最容易研究的过渡。"**

**观测方式**
- 主指标：系统给出的区间中段 `band[1]` 与你独立标注的"最像我"的位置是否落在同一段；
- 次指标：一致性是否在 I-3 → I-4 段显著高于 I-2 与 I-5。

**对账表**

| 轮次 | 系统 band[1] | 你的独立标注 | 是否一致 |
|---|---|---|---|
| | | | |
| | | | |
| | | | |

**若推翻则删**
- 主指标失败（一致性未显著高于其他段）→ **删除** `规格_统一模型_v1.md §6` 中"里程碑最易观察"这一前提，并**重新审视** `state.py` 的 `OPPOSED_PAIR_BONUS`（半级规则只对遵奉以上生效这一点依赖该前提）。
- 次指标失败 → 只保留主指标结论，删除"最容易研究的过渡"这一表述在规格中的引用。

## §2 ⚠️ 首要风险：向导规则

**预测原文**：只在用户自发出现 L+1 信号时才给 L+1，比始终给 L+1 更有效。

**为什么这是首要风险（必须写在最前面）**
> [E] 引丹姆伯：**"总是在一个比理想水平稍微复杂的水平上选择刺激物。这些刺激物称作向导。"**
>
> **但丹姆伯的是刺激物研究（视觉／认知复杂度），卢文格引它时用的措辞是"几乎一致"和"看来"——他自己也没有把它实证化。**
>
> 我们把它做成了规则（`rules/behaviors.json → pacer_rule`），这是一次**跨域偷渡**。所以它排第一。

**观测方式（A/B 对照）**
- 条件 A：现行规则（L+1 需用户自发出现过 L+1 信号才允许）；
- 条件 B：无条件给 L+1；
- 指标：随后 k 轮内用户自发生成"更高水平表述"的比例。

**对账表**

| 条件 | 轮数 | 随后 k 轮出现 L+1 自发表述的轮数 | 比例 |
|---|---|---|---|
| A 有触发条件 | | | |
| B 无条件 | | | |

**若推翻则删**
- 若 A 不优于 B → **删除** `rules/behaviors.json → pacer_rule.trigger_condition`，并删除 `pacer_rule.status: ASSUMPTION` 所依赖的整个向导机制，`behaviors.json` 中 `pacer_eligible: true` 的两个行为（`REFLECT` / `ASK_MUST`）降为纯平行回应。
- 若 B 更优 → 同样删除触发条件，并把 `max_jump` 从 1 放开（但需先讨论：放开跳级会撞上格兰特与格兰特的匹配律）。

## §3 两条方向线是否其实是同一条

**预测原文**：`want_like_gap` 低的轮次，`attitude_clause` 出现率显著更高。

**为什么这么预测**
- `[D]` 想要/喜欢分离 → 提示水平在指向段之下；
- `[M]` 态度句 → 提示水平在指向段之上；
- 若二者从不共现、且总是同向，那它们只是同一变量的两种说法，我们白白维护了两条线。

**观测方式**：2×2 列联表。

| | `attitude_clause` 命中 | 未命中 |
|---|---|---|
| `want_like_gap` 命中 | | |
| 未命中 | | |

**若推翻则删**
- 若两线**永远同向**（无一例 CONFLICT）→ **删除** `state.py` 的 `_frankl_line`，方向判别只保留一条线；同时删除 `schema.json → state.direction.lines`。
- 若两线**高度共现**（同一轮总是一起出现）→ 删除其一，并在规格中注明方向判别为单线，`CONFLICT` 状态随之作废。

## §4 对立观念并存的机制

**预测原文**：按"两个对立观念并存"提示后，用户会在数轮内自发生成更高水平的表述。

**为什么这么预测**
> [E] 第九章（从数据读出的**机制**，不是编码规则）：**"从遵奉阶段开始，个体头脑中会共存两个相反的或相对的观念……这可能就是一条途径，通过这条途径，个体获得了看到下个更复杂水平的能力。"**
>
> 注意卢文格自己用的是"这**可能**就是一条途径"——他也只是假设。

**观测方式**：凡 `behavior == JUXTAPOSE` 的轮次，记录其后 k 轮内是否出现新的高段标记。

| JUXTAPOSE 轮次 | 后 k 轮新增的高段标记 | 是否发生 |
|---|---|---|
| | | |
| | | |

**若推翻则删**
- 若发生率与随机轮次无差异 → **删除** `rules/behaviors.json → selection_rules.ladder` 中 `JUXTAPOSE` 那一级的优先权，并把 `markers.json → opposed_pair._note` 中"L4 允许使用 JUXTAPOSE"的授权撤销。
- 该行为可保留但降级为 `REFLECT` 的变体，不再声称它有任何机制作用。

## §5 门控的必要性

**预测原文**：四字段门控比模糊匹配更少误判。

**为什么这么预测**
> [E]：**"一个在遵奉量表上得分较高的人能够被假定是处于遵奉阶段的人，但是一个在遵奉量表上得分较低的人可能是前遵奉者或后遵奉者。"**
>
> 因此若固化阈值只看重复次数，S 会把两种相反方向压成一个映射。

**观测方式**：统计"同一签名族内出现相反方向证据"的次数（即本应被门控挡下、若模糊匹配就会误命中）。

| 轮次 | 签名键 | 出现的相反方向证据 | 门控是否挡下 |
|---|---|---|---|
| | | | |

**若推翻则删**
- 若此类情形**从未出现**（样本量足够的前提下）→ 说明窄化牺牲了泛化而没换来安全，**删除** `state/schema.json → signature.fields` 中的 `intensity` 与 `time` 两字段（保留 `blame` 与 `mutability`，因这两条各有独立理论依据）。
- 若挡下率过高（S 几乎从不命中）→ 说明门控过窄，此时**不删规则**，而是先检查 `§6 覆盖 vs 固化` 那个未解问题。
