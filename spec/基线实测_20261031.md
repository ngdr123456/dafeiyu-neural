### 校验调用是否变慢（用户明确问）

```
elapsed_ms：n=35｜min 1750｜p50 5042｜p90 19978｜max **36718**｜均值 8533
超过 10 秒的轮：**10 / 35**
```

**★ 我必须说清一件事：**这不是"预算变大所以变慢"，是"预算变大所以那些本来被砍掉的调用现在真的跑完了"。**

**证据：耗时与 token 数强相关（6000 token → 36 秒；220 token → 1.8 秒）。
模型生成多少 token 是它自己决定的 —— 预算只决定"够不够砍到"。**
**⇒ 旧行为是"快，但那 6000 token 的活被扔掉、然后记一个 ValueError"。
新行为是"慢 36 秒，但真的校验完了"。**

**⚠️ 但 36 秒一次校验是**不可接受**的（尤其 shell.py 真人交互）。
这是一个**新暴露的性能问题**，我要记下来，不在本批修。**
