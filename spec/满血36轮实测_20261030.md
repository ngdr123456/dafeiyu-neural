## 五、主线任务 3 的核查（先汇报，不改）

**他问：机制层在不在哈希名单、最佳无侵入耦合点在哪。**

### 1. `mechanism.py` 在名单里（engine 63 个之一）

### 2. 现在的耦合现状

```
Mechanism.step 吃的是：pr.markers（词表标记）+ len(raw)（字数）
**完全不吃 cognition 的产出**（WANT_MUST / COST_FEEL / FIXED / ACTION / CONFIRMED / REBUFFED）
⇒ 所以"意识海"和"底层机制"目前是**两条平行线**，只在 `_build_frame` 的简报里汇合。
```

### 3. 我建议的无侵入耦合点（**只读，不改机制层内部**）

```
位置：`pipeline.turn()` 里，`mst = self.mech.step(...)` **之后**、`mcond = classify(...)` **之前**。
做法：把这一轮的认知产出作为**只读输入**传给 `classify()`，而不是写回机制状态。

理由：
· 机制层的 `w/l/a/e/tension` 有明确的量纲与公式（名字即公式），
  往里硬塞"这轮抽到了 WANT_MUST"会破坏那条纪律。
· 但 `classify()` 是**把状态映射到条件 ID** 的地方 ——
  在那里加一条"若 cognition 抽到 WANT_MUST 且无对应 COST_FEEL，则条件偏向 WANT_NO_LIKE"
  是**只读的**，不动状态演化。
· 而且它是纯本地规则，可测、可回退。
```
