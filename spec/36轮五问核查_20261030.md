## Q1：`boldness 0.89` 与 REBUFFED 的 −0.06

### 那次 REBUFFED 在 **轮 9 → 轮 10**

```

### ★ 但算术有两种读法，都需要 `_settle_traces` 才能定案

```
读法 A（13 确认 / 0 受挫）：0.50 + 0.03×13            = 0.89  ✓
读法 B（15 确认 / 1 受挫）：0.50 + 0.03×15 − 0.06×1   = 0.89  ✓

**两种都对得上 0.89 —— 这就是问题所在：光看终值分不出是哪一种。**

**★ 而离线重算（用台账里存的 claims）得到的是 **CONFIRMED 13 / REBUFFED 1**，
对应 **0.83** —— 与落盘的 0.89 差 0.06，正好是一次 REBUFFED 的量。**

**⇒ 所以最可能的事实是：**
```
落盘的 0.89 ≈ **13 次 CONFIRMED 都结算了，而那次 REBUFFED 没有**
（0.50 + 0.39 = 0.89）
```

**⚠️ 但我**没有证据定案**：`_settle_traces` 是**进程内列表**，
36 轮跑完进程就退了，**没有落盘**。
⇒ **要定案，必须把 settle 留痕写进台账（一行改动）。这一轮按你的要求没改。**

**★ 另有一个差异我必须指出：线上判定用的是 `extract()` 当场返回的 claims，
离线用的是台账里 `cognition["claims"]` 存的（可能是合并两遍后的）。**

## Q6：轮 8 / 36 的显式退缩语，REBUFFED 为什么没抓到

### 命中情况

```
轮  8：他含「算了，不说这个」  is_closing=**False**  lean=1.0  她 → QUESTION（继续追问）
轮  9：他含「不想说」         is_closing=**False**  lean=1.0  她 → QUESTION
轮 36：他含「你别说」         is_closing=**False**  lean=1.0  她 → ASK_DETAIL（模板）
```

**★ 36 轮里 `is_closing=True` 只有 **1 轮**。`lean` 只有两个值：**0.78 和 1.0**。**

### ★★ 为什么 REBUFFED 抓不到

```
REBUFFED 的判据是：**BOLD 在 t 轮，t+1 轮反应弱**。
而轮 8 的「算了，不说这个了」**就在 BOLD 那一轮的同一句原话里** ——
它不是"她探照之后他的反应"，而是"她探照之前的现场"。
⇒ 判据的口径与现象**对不上**：
   现象是「他已经退缩了，她还在往深处问」；
   判据问的是「她问完之后，他退了吗」。
```

**★★ 而且 `is_closing` 一次都没在这些轮触发** ——
**说明机制层的 `is_closing` 不认这些口语退缩语。**（它的口径我没有逐行核。）

### ★ 评估：「显式退缩/边界用语」作为判据的可行性

**可行，而且它比"字数比"更准。理由与代价：**

```
① 它是**字面可核对**的（跟 FIXED/ACTION 抽取同一套纪律，不靠模型判）
② 它抓的是**关系层**的信号："他把门关上了"，而不是"他话说短了"
③ 它可以直接用来做**一件现在做不到的事**：
   当她 BOLD 而他的原话含显式退缩语 ⇒ 那不是"深度遭遇"，是**越界**。
```

**⚠️ 但有三条必须先想清：**
```
· 汉语里"算了"有多个意思：「算了，不说这个了」（退缩）vs「算了，反正也这样」（认命）
  —— 前者是边界，后者是死局。**同一个词，判据不同。**
  初版建议只认**带宾语的**退缩（"不说这个""别问这个""换个话题"），
  不认光杆"算了"。
· "你别说成一回事"（轮 36）不是退缩，是**纠正**（他说的是"别把两件事混为一谈"）
  ⇒ 我把它算进"边界语"可能是**误判**。这一条我要更正自己。
· 一旦把"越界"记为负向，就必须回答：**她怎么知道她越界了？**
  现在没有"他明说了边界"这个输入给她。⇒ 判据之外还要一条**注入**。
```
