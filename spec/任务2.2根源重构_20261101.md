## 三、★ 三个坑（都是测试抓到的）

```
① `source_record(index, row)` 只收 2 个参数、且 row 必须是 dict
   —— 我按 3 个参数调、还传了 LedgerEntry ⇒ 抛异常被 `_swallow` 吞掉 ⇒ sources=0

② `p._input_origin = {...}` **无效**
   —— `turn()` 第一行就是 `self._input_origin = normalize(input_origin, raw, topic_id)`，
      默认 `input_origin=None` 会把它覆盖掉 ⇒ 台账里 session_id 全是 None
   —— 必须**作为参数**传：`p.turn(raw, input_origin=...)`

③ `normalize()` 要求 origin 里带 `schema=1` / `input_sha256=digest(raw)` / `topic_id`
   —— 随便传个 dict 会抛 `Input provenance schema/hash mismatch`
```

**★ 第 ② 条值得记：我好几处测试都在用 `p._input_origin = {...}` 的写法（如 `test_answer_first`），
它们**现在能过是因为不依赖 session_id**；一旦依赖，就全是 None。**
