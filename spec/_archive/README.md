## `_archive/` 怎么分的

按文件名里的 `_YYYYMMDD` 取月份：

```
_archive/2026-10/          74 个
_archive/2026-11/           2 个
_archive/无日期/             3 个
_archive/根目录旧文档/        7 个
```

**★ 为什么按月份而不按主题：**
```
这些是**按时间写的报告**（"这轮改了什么、数据是什么"），
它们的阅读方式本来就是"按时间往回翻"。
按主题分反而会被后来的重新分类推翻（我这一路上就改过好几次口径）。
⇒ 按月份最稳：不会再变。
```

**如果你想要按主题分（如 认知/意识海/验收/架构），说一声，我可以再分一层。**
