## 一、他的诊断是对的：`_needs_fact_guide` 漏了 `relational_context` / `own_task`

**他的推理：**
> `actual_source_change_reconsider` 依赖 `FACT_GUIDE` 里那句
> **「旧话与新话冲突时保留更正，不把旧说法当成当前事实」**。
> 但如果那个用例的提问原话没命中 `_FACT_ASK` 正则，而它是靠 `self_goal.applies(frame)` 触发的，
> 那么 `FACT_GUIDE` 根本没注入 ⇒ 那个 case 就挂。

**⇒ 完全成立。我改之前 `_needs_fact_guide(raw)` 只看正则。**

### 修法：从"只看原话"扩成 `Frame` 的方法（三条任一）

```python
def needs_fact_guide(self) -> bool:
    """三条任一成立就要注入：
      ① 原话里出现事实追问/指代（_FACT_ASK）
      ② **关系记忆核对已激活**（relational_context["groups"] 非空）
      ③ **声明目标流程已激活**（own_task["goal_selection"]["selected"]）
    """
```

**实测四种情形：**
```
日常倾诉「今天有点累」        → False  ✓（去助手化不受影响）
事实追问「押金由谁收着」      → True   ✓
关系记忆激活（groups 非空）   → True   ✓
目标流程激活（goal_selection）→ True   ✓
「A 还是 B」纠结轮            → **False** ✓（这是关键：纠结轮不该背客服条款）
```
