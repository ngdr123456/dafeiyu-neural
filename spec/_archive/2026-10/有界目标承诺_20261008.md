# 有界目标选择、承诺接续与操作兑现

本轮承接 T37、D-020、D-022、D-029～D-031 和上一轮 T45 自身作答闭环，推进 `SELF_GOAL_ORGANISATION`。固定的工程作答责任仍保留；新增的是大脑可以在当前来源范围内声明一个具体目标，或选择不采用目标。声明会影响实际回复，失败、接续、退出和来源变化都有配套记录。

## 回望原书与过去的逻辑

《自我的发展》p71以联系法则解释结构，p73指出结构影响选择方向和可塑性范围，p76～77要求新组织的原则与相继组织的连续性。因此本轮不靠增加“成功次数”宣布发展，而是把既有的对象／关系／时间／来源／更正组织，同时用于目标的允许范围、承诺接续、回复检查和后来重审。p64要求人格各方面的联系，p68保留自我意识与自由体验的局限；本轮仍是局部工程接线，不能说整体人格或人的自由体验已经实现。

《贪婪的多巴胺》“规划与计算”部分区分想要与如何获得，并讨论控制回路的规划；前面的奖赏预期误差讨论要求区分期待与实际结果。本轮在生成之前声明操作期待，之后独立核对逐字条件，保存 MATCH／MISMATCH／UNKNOWN，并让 MISMATCH 保持承诺未决。该差异不是生理多巴胺或主观奖赏，不写入 r，不借此升级。大脑选择一个引用任务，不证明它对该任务具有人的价值体验；以后必须论证更一般的主体目标和语义兑现，不能靠最容易完成的引文动作优化意义。

《活出生命的意义》关于自由与责任的论述要求选择与担当具体问题联系。这里系统选择和核对自己的作答任务；不把用户的联系人、打算或生命意义变成系统的愿望，也不替用户选择。允许 NONE 和退出，是有界程序中的选择空间，不是原书对人类自由的证明。

以上均为可检验的工程翻译，不冒称三书给出了这些函数或阈值。R1/R2/R3、硬伦理、感知闸门、管理员冻结方法、旧正式经历及阶段计数保持原逻辑。

## 接进实际管线的过程

```mermaid
flowchart LR
    A[同来源原话关系与明确更正] --> B[允许的逐字操作目标]
    B --> C[大脑选择一个目标或 NONE]
    C --> D[生成前声明与期待]
    D --> E[实际作答和原有闸门]
    E --> F[核对选定文本中的引文]
    F --> G[兑现操作或保持承诺未决]
    G --> H[后来同对象同关系的另一问法]
    H --> B
    A --> I[来源变化触发重审]
    I --> B
```

`engine/self_goal.py` 只开放 `QUOTE_SOURCE_SET` 操作。允许范围来自当前关系记忆，不能自由创造命令、对象、事实或程序：

- 只针对当前明确的关系查询，限既有 custodian／contact／location。提到或引用别人的问句不自动成为自己的任务；对象或时间含糊、来源被截断、条件超限时不提出目标。
- 目标带对象／关系／时间键、来源 ID、原文哈希、起止位置和逐字片段。每个片段重核原文；非肯定角色与被明确更正的旧说法不成为当前目标。语义抽取仍可错，来源角色不是独立世界核实。
- 未解冲突必须覆盖所有当前不同值，不能偷偷只选最后一条。暂限两个不同值和可容纳的短引文；更大的情境保留既有未知及关系记录，不硬塞进该算子。
- 大脑以单次有界 JSON 请求选择允许的 goal_id 或 NONE。编号和结构由程序校验，模型理由只存为数据，不作为执行指令。没有可选目标不增加请求；既有运输重试上限仍适用。
- 选定后，本轮生成候选必须引用全部选定片段，含标点；否则在原有两次尝试以内重做。这个局部要求同时服从全部原有校验，不绕过内容复核或伦理。
- `use_goal_planning=False` 可关闭此段作干预对照。没有协议能力的外部思考接口不冒充做了选择。

## 承诺怎样接续、重审和退出

声明和结果与同一新台账行一起保存，没有第二份可漂移的目标状态。重启后从已提交台账派生；扫描最多128条同来源记录，当前简报最多4个相关承诺。检索未找到不能推出从未承诺过。

承诺以对象／关系／时间及来源程序匹配，故同一对象换一种问法也能接续；另一个对象、关系、时间、来源种类或训练 run/session 不能借用。作废、不配套痕迹和不匹配当前允许程序的目标不能直接复活。

PENDING 是未兑现的操作承诺。后来重新选择同一目标可以接续；选择 NONE 会退出当前相关的未决目标；以后仍可重新声明，退出不是永久禁止。选择请求失败或返回未经允许的编号，不默默抹掉仍有有效来源的旧承诺。旧来源已经变化时不沿用旧目标；待办的旧程序退出，新的声明必须重新匹配当前材料。

FULFILLED_LITERAL 只表示：通过原校验选定的本轮文本，满足已声明的逐字引用条件。它不证明用户收到了，不证明外部事实为真，也不证明回答的归属、时态或整段语义都正确。源于同模型的 PASS 仍属于相关意见。语义贴合、用户满意和收到状态继续 UNKNOWN；既有自由生成动作仍可为 UNCLASSIFIED。

来源更正时，过去已经完成的操作事实不被擦掉，但旧操作不能充当当前目标已完成的证据。新的来源进入新的程序版本 ID，须重新选择和核对。这与上一轮“新依据允许改判、失败历史不删”的逻辑相嵌合。

## 本轮可检验的改变与边界

同历史、同候选序列的关闭对照中，旧管线放行不带引文的候选；开启目标段后该候选被当前承诺检查阻断，第二个含原文引号的候选被选择返回。影响发生在实际输出，不只在报告字段。

`tests/test_self_goal.py` 检查选择、实际干预、重启与不同问法、退出后重新声明、来源更正、未知请求对有效待办的接续、对失效待办的撤回、冲突双引文、来源哈希／截断／角色／作废／痕迹、对象及显式时间隔离。额外的故意破坏检查检验断开选择、绕过目标闸门、跨对象复用、忽略退出、沿用失效来源、把逐字结果冒充语义兑现、略过原文哈希。

目标家族及其编译器仍由工程设计；本轮没有开放任意新原则、人生目标或主体价值的生成，也没有把局部选择等同于人格发展。该目标会促使引用更完整，也可能令回答更像核对原文；应在后续意义和关系的任务中检查收益与损失，不能把引用数量当最终目标。

## 桌面、证据与下一段

首次完整实际诊断在原有检查项下通过，但人工回看发现记忆消融回答说“这件事我这儿没有记录”，完整保存来源却存在。保留 [实际反例及来源见证](有界目标承诺记录范围反例_20261008.json)、[原记忆报告](有界目标承诺记忆模型复验_20261008_记录范围修复前.json)和[原完整报告](有界目标承诺真实诊断_20261008_记录范围修复前.json)。旧协议通过不能扩大成该句语义可靠。

据此补 `engine/memory_scope.py`：从同来源、未作废且原文哈希配套的记录取得相关原话存在的正向见证，仅给大脑记录存在及检索范围，不补回关闭关系检索后缺少的姓名或答案。确定有相关原话时，独立程序检查阻断“我这儿没有记录”一类未限定范围的断言；当前片段限定、引用、疑问、禁止及否定该断言保留各自作用域。没有见证不证明原话不存在；分类槽位仍可错，外部事实不据此确认。最终实际消融检查额外要求该见证并核对输出范围，原有内容意见不能单独放行这类反例。

桌面沿用现有区域，增加“最近有界目标（保存状态）”及“逐字操作已核对／承诺待兑现／已退出相关未决目标”，同时保留“语义结果待核验”。现有 exe 可关闭重开读取外部源码。
