## 一、他的两条算得都对

### 破案 1：僵尸悬念（Zombie Focus）

**他的算术**：`P1 input` 只有 5 次，`P2 unfinished` 却 21 次
⇒ 源头只有 5 条，怎么可能消费 21 次？**因为同一条挂了 4 轮。**

**⇒ 修（6 行）：**
```python
# P2 检查：必须 ① 同会话 ② 当前轮 - uf.turn == 1 ③ 否则直接清空
_uf_fresh = (isinstance(_uf_turn, int)
             and self._turn_seq - _uf_turn == 1
             and (not _uf_sess or not _cur_sess or _uf_sess == _cur_sess))
if _uf.get("quotes") and not _uf_fresh:
    self._unfinished_focus = None       # 过期悬念：清掉

# 选中 P2 后标记"用完即焚"，本轮结束若没产生新悬念就清空
self._unfinished_consumed = True
```

**★ 并给 `unfinished` 的 hint 补上逐字引文要求（对齐 P1/P3）：**
```
原来：如果这一轮的话跟这有关，顺着往下接            ← 软绵绵，没要求引原话
现在：请直接用「我还在想你刚说的『…』——」…
      **务必带引号逐字点出其中至少一段原话。**
```
**⇒ 依据：P1 落地 60%、P3 落地 50%、P2 落地 **0/21** —— 差的就是那一句。**

### 破案 2：第一人称想要掉到 0/36

**根因 A：门槛设在 `boldness >= 0.60`，而这 36 轮**最高只到 0.59**（终值 0.56）

**⇒ 修：下调到 `>= 0.52`（净确认 ≥1 次），并且 `last_encounter == "CONFIRMED"` 也解锁。**

**⇒ 修：只给真碰壁 —— `last_encounter == "REBUFFED"` 或 `boldness < 0.42`；
R1/R2/R3 的常规平滑**不下全局禁令**。**
