## 已落实的代码与桌面显示

1. 固定语料与题面的作者身份改为未经独立验证，移除“人写、没有自证循环”的无证据断言。模型生成的新话单独标 `tutor_generated`，原种子来源、种子和实际输入哈希分别保存；合成输入保留种子编号。
2. 话题编号、实际输入来源贯穿 Trainer→Pipeline→Ledger；关系反馈与冻结结构案例也保存输入来源。反馈者身份与输入作者是两个字段，不能互相冒充。直接调用未声明来源的输入标未知。
3. 评价版本升为4，后续记录含实际来源、话题、批次编号、轮编号及完整机制快照；普通轮返回给训练师的快照与落盘快照统一，修复旧有 dev 字段只进台账的差异。已写的本轮记录不反向伪造当时不存在的新字段；本轮读数同时保存在运行报告。
4. 严格训练入口遇到 API 不可用、训练师生成失败、理解／评价失败或大脑／关系学习降级即停，并保存已完成轮数及失败原因。允许 `max_turns` 限制续跑规模，避免“三场”规则迫使多跑。运行历史新格式分别记录本次与累计轮／场数，不改旧历史口径。
5. 响应诊断由训练入口的只读 reader 包装采集，保留原 Admin 方法及既有 AST 冻结检查，不修改判定逻辑或建立第二份管理员。没有自动把失败判为 `none` 的成功意见。
6. 既有桌面训练入口使用严格运行；家教页将失败排除出七类有效判定，失败或中断显示在原有控件和文本里，不显示绿色完成或强制100%。没有新增定时器或控件。稳定 exe 读取外部最新源码，不需重打包。
