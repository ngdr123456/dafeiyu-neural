### 修掉的两个 bug（都是我自己的）

**bug 1：`subject_declared` 判错，放出 4 条假配对**

```python
# 第一版
return bool(raw) and bool(normalize_subject(raw))
# ⇒ subject="鞋"（单字死物，归一化成 ""）被判成"未声明"
#   和另一条"未声明"的一起走了宽路
#   放出 ('鞋','')、('水','')、('车','')、('你','') 四条假配对

# 修后
return bool(raw)      # 只看"填了没填"
```
**理由：单字死物既然归一化后为空、无法参与 subject 匹配，就**更不该**获得"都为空可以配"的许可。**

**bug 2：跨轮的"双空宽路"本身就是错的**

```
曾经：两条都没声明 subject + 是 FIXED+ACTION ⇒ 允许配
实测：走这条宽路的 7 条里 **好 3 / 假 4（57%）**
砍掉后：16 条，好 11 / 假 1（6%）
⇒ 只少 3 条好的，少 4 条假的
```

**★ 原则：跨轮配对如果没有 subject 证据，那两条只是"都在他说的某句话里"，
**不足以说它们是同一件事**。"死局 vs 活口"在**同一轮**内由算子 4 做，不需要跨轮去凑。**

## 三、★ 剩下那 1 条假阳性是**字面规则的天花板**

**第 58 轮：**
```
WANT_MUST「还得我自己搬那台打印机」
ACTION    「搬打印机是真懒得动」
⇒ 那不是反差，是**同一件事的两种说法**
```

**我试过用字符重合率拦（Q5.1），实测 `_lcs_ratio` = 0.33 < 0.40 ⇒ 放行。**
**⇒ 因为两句措辞不同（"还得我自己搬"vs"真懒得动"），只有"搬打印机"3 个字重合。**

**★★ 所以：纯字面规则**无法**区分"同一件事的两种说法"和"两件有张力的事"。**
**这正是我申报单里报的风险 ②（label 是模型判的）在"自发想"上的放大版。**

**⇒ 我不打算再调阈值（那是拿数据凑判据）。这一条我认为可以接受：**
```
8% 假阳性 + 召回 11 条（215 轮里）
而这条 8% 是**纯字面**压出来的，没有一次语义猜测
```

## 四、★★ 一个必须让 Gemini 知道的取舍

**我砍掉"双空宽路"时，丢掉了 4 条我认为**好**的配对：**

```
109 「你现在跟我说这些，怪谁还有啥用？」+「站起来过一次」
110 「站起来那会儿就灭了」+「就又蹲回去了」
153 「结果是这样」+「是我选的」
195 「我知道是我放的」+「没多问一句」
```

**⇒ 这 4 条**确实有张力**，但它们**都没有 subject 证据**（抽取时说不清对象）。**

**★ 所以这是一个**召回 vs 精度**的取舍：**
```
保留双空：21 条，好 17 / 假 4  ⇒ **19%** 假阳性
砍掉双空：12 条，好 11 / 假 1  ⇒ ** 8%** 假阳性
```

**我选了砍掉，理由是「宁可她这一晚什么都没想，也不要她想到一个假的」。**

**▶ 但你可能有不同判断 —— 如果你认为那 4 条值得留，那就把宽路加回来，代价是假阳性 8% → 19%。**
