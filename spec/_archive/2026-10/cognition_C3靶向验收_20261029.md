## 二、改了什么（四处）

### 1. 抽取 prompt 语义收紧（含负例）

```
FIXED  只抽：已经发生、无法撤回的**人际/生命/现实既定处境或遗憾**
       严禁：做饭/家务/天气/路况等纯物理过程细节（水添多了、汤底浑了、鞋上有泥、灯坏了、
             咖啡凉了、路上堵了俩小时）
             主观困惑或泛泛评价（别的什么没了、没用）

ACTION 只抽：面对处境时**自己做出的、有心理分量**的应对/退缩/隐瞒/忍耐/卡住
       严禁：充当时间背景的日常过场动作（挂了电话、站起来那会儿、车开走以后、
             开柜子拿浴巾、火我关了）
             不受控的纯生理条件反射（手抓着桌沿）
             意思不完整的半截残句（我低头说了句、我一拧开）
```

**★ 并在 prompt 里加了一句总纲：**
**「一段原话里如果只有物理细节、没有人的取舍，就不要抽 FIXED 或 ACTION。」**

### 2. 两条本地守卫（只在算子层生效，不写进 `_literal_claim`）

```
① 最小信息量：去标点后 ≥4 字
   ★ 例外一：含引号引述（引号里本身有信息）
   ★ 例外二（实测逼出来的）：<4 字但**含人的取舍**（退缩/动作/欲求词）⇒ 放行
     依据：一刀切会把垃圾「没用」「试过了」「还在」
           和好东西「没敢说」（3 字，含"没敢"）一起砍掉
② 禁截断尾词：ACTION 不得以悬空动词结尾（说了句/了一句/一拧开/看着/走到…）
```

### 3. `Thought.hint` 从**固定台词**改成**给大脑的结构简报**

```
旧（38 条里 36 条用同一句）：
  「{a}」这一半已经定了；「{b}」这一半是你自己做的。
  ⇒ 一眼看出是模板；而且把行 187 的「我说吃了」（掩饰）
    说成"这是你自己做的"（选择）—— **固定连接语会把好素材说歪**

新（每个算子一句专属简报）：
  「【你注意到的两处原话】一边是既定处境「{a}」，另一边是他当时的应对「{b}」。
    不要用固定套话，只把这两处原话用引号并排点出来，或就「{b}」轻轻问他一句。」
```

**★ 关键：`hint` 是**给 `Thinker` 的内部注意力焦点**，不是给她照念的台词。**
**§ 而 `C5` 的本地核对**只认 `quotes` 的两段逐字命中**，不核对连接词 ⇒ 不写死台词不削弱可确认性。**

### 4. 两处算子放宽（离线/历史数据）

```
算子 2（欲求-代价）：当本轮**没有鲜活 mech** 时（历史 191 行全无 phase），
  退回"同轮同时有 WANT_MUST 与 COST_FEEL"这条纯字面条件
```

**★ 在线运行时 `phase_by_turn` 有值 ⇒ 仍走严格路径（以 phase 为准）。**
