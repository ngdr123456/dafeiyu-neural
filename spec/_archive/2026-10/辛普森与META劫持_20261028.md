**⇒ `intent == "META"` 一旦成立，`mech.step()` / `devlevel.update()` / `responder.choose()` 全部不执行。**


## 三、我必须撤回的一条

**我在 `spec/judge重判实验_20261028.md` 第十节写的：**

> 「★ 长度效应**反转**：Claude 那条只在带读数的标签下成立」

**⇒ 这条**是辛普森悖论**，应撤回。**

**正确写法：**

```

  模板行    <40 字 82%

⇒ 混在一起算出的「<40 字 35%」既不代表模板行也不代表非模板行，是加权平均的假象。
⇒ **长度不是可用的信号**（这一点原来的结论对），但**理由要改**：
   不是因为"方向反转"，而是因为**它测的是"这一批里模板占多少"**。
```

## 四、这条链连起来 —— 真正的因果顺序

**发现 3 + 发现 2 合起来才完整：**

```
① 家教话里有「你说…」「你想过没有…」等口头禅
   ⇒ intent 被判成 META
   ⇒ pipeline.py:362 早退
   ⇒ **mech.step() 不执行**（w/phase 冻结在 9.4 / NO_TENSION）
   ⇒ responder.choose() 不执行 ⇒ 行为退回模板（REFLECT）
   ⇒ 输出是**写死的模板**（「你用了这样一句话：「…」」）
   ⇒ 被 tutor 判 mechanical

② 而模板行的输入通常很短（中位 15 字，因为 hand_corpus 的短题面多）
   ⇒ 「短输入 → 高机械率」的假象
```

### ★ 这改变了改进的目标

```
以前的说法：让她别写得像模板
真正的病灶：**模板本身出现在自由对话里**，因为机制层被跳过、阶梯兜底到 REFLECT

⇒ 那 60 条被骂「像模板」的，**至少 26 条（43%）根本是她没参与写的**（是模板）
⇒ 「像模板」这个罪名，近一半是**冤枉的** —— 那本来就是模板，不是她的生成
```
