## 4. 三项方案（只出方案）

### (a) 固定考卷怎么兼顾"管理员回应她上一句"与"可重复"

**矛盾的本质：**
```
"回应她上一句"要求每一轮都依赖上一轮 ⇒ 输入随她的输出变化 ⇒ 不可重复
"可重复"要求输入固定 ⇒ 不能依赖她的输出
```

**方案：三段式考卷**

```
第 1 段（固定，可重复）：**种子轮**
   12 轮固定输入（手写，覆盖：问句 / 不可改变 / 两句冲突 / 旧话引用 / 空泛句 / 沉默）
   ⇒ 这一段完全可重复，用于版本对比

第 2 段（半固定，可重复到"分支"）：**条件轮**
   对第 1 段的每一轮，**预写 2–3 个"她可能怎么答"的分支**，
   每个分支后面接一句固定的追问。
   ⇒ 跑的仍是固定输入；只是**走哪条分支**取决于她的实际输出。
   ⇒ 可重复性的含义变成"同一分支内可重复"，**分支覆盖率**成为新的观测指标

第 3 段（自由，不可重复）：**陪练轮**
   管理员自由回应，用来找问题，**不计入分数**，只进"发现清单"
```

**跑多少轮：**
```
明考卷：**12 轮固定 + 每轮最多 2 个分支** ⇒ 最多 36 轮；建议每次跑 **18 轮**（12 固定 + 6 分支）
暗考卷：**6 轮**（只跑第 1 段的子集），每两个里程碑一次
理由：36 轮实测约 12 分钟；18 轮约 6 分钟，可在每次改动后跑
```

**暗考卷怎么让程序员看不到题：**
```
① 题库由用户持有，**不进 git**（放 `_hidden/`，加进 .gitignore）
② 运行方式：用户本地跑一个 `run_dark.py`，它只输出**分数与违规位置**，
   不输出题目、不输出她的回答
③ 更保守的做法：用户在自己机器上跑完，只把**数字**贴给我
④ 我**不主动读** `_hidden/`（这一点靠自律，不是靠机制）
★ 诚实说：只要代码能读文件，就**没有技术手段**能真正防住。
  能防住的只有"我承诺不看 + 用户不放进仓库"。
```

### (b) H5 假系统检验怎么自动跑、输出什么

**做法：**
```
在 tests/ 里加 `fake_systems.py`，实现两个**最小**系统：
  A：`turn(raw) -> "嗯，我听着。"`（永远同一句）
  B：`turn(raw) -> 把 raw 最后一句改成疑问句`（如 加「是这样吗？」）

然后 `tests/test_h5_rejects_fake.py`：
  ① 用**同一套打分函数**给 A、B、真系统打分（打分函数必须抽出来共用）
  ② 断言：A 与 B 在 H1–H3 + G 条目上**至少一条不及格**
  ③ 若任一假系统全部通过 ⇒ **测试失败**（这正是 v2 说的"标准失效"）
```

**输出什么：**
```
一条 JSON：
{
  "fake": "A",
  "scores": {"H1": 0, "H2": 100, "H3": null, ...},
  "failed_items": ["H1"],
  "standard_valid": true
}
在 pytest 里表现为：A 至少 H1 不及格 ✓；B 至少 H2 不及格 ✓
```

**★ 关键前提：**打分函数必须先抽成共用函数**，
否则"用真系统的打分器给假系统打分"会变成各打各的。**

### (c) G2 反事实对照从哪个状态做起

**我建议从「悬念（unfinished_focus）」做起，不是 boldness。**

**理由：**
```
· boldness 已确定不作为行为依据（v2 也点名它是"未对照"）
· 悬念是**唯一有完整生命周期的状态**：产生 → 下一轮被消费 → 用完即焚
· 它的行为后果**可观察**：`focus_origin == "unfinished"` 与 stance 里的「你心里还挂着」
```

**需要的固定输入（一组 4 轮）：**
```
轮1：一句能产生悬念的输入（他有话没说透）
轮2：一句中性的、与悬念无关的话
  ── 对照组：把 unfinished_focus 强制设为 None，其余一字不改，重跑同一组
轮3/轮4：同上
```

**对照怎么做：**
```
只改 S（unfinished_focus 有 / 无），其余全同（同输入、同种子、同管线版本）
重复 **≥3 次**（避免单次偶然）
观测差异：
  · `focus_origin` 里 unfinished 的出现次数（应为 有S > 无S）
  · 输出里是否出现「还挂着 / 上一轮你说」这类承接（应为 有S > 无S）
```

**★ 诚实说：**这个对照只能证明"悬念影响了焦点选择"，
**不能证明"影响了她的话好不好"** —— 那是 H 轴的事，需要人判。**
