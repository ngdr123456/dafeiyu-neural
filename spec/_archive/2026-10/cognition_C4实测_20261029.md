## 一、落地了什么（C2 + C4，不碰 C5）

### C4：`Frame` 新增两栏 + 简报注入 + 锚点退居次席

```python
# think.py Frame
thought: str = ""            # 给大脑的一句话结构简报
thought_quotes: tuple = ()   # 它引用的两段逐字原话（C5 核对的唯一依据）

# FRAME_USER：只有当 thought 非空时才注入这一栏（空时连标题都不出现）
【你此刻注意到的两处拉扯】
{thought.hint}

# FRAME_SYSTEM 第 6 条新增：
★ 若上面有【你此刻注意到的两处拉扯】，就以它为准：把这两处原话用「」并排点出来，
  或顺着其中一处轻轻问他一句。**此时不必再去抓单个锚点词** ——
  单字锚点（「我妈」「桌子」）会把注意力从整条冲突结构上拽偏。
```

**★ 最后那句是 Gemini 提醒的防覆盖：实测证据在行 187——**
**旧输出是"你用了这样一句话：「…整句…」"，新输出是「我说吃了」——说这句话的时候，你人在哪儿？**
**⇒ 她抓住了「我说吃了」这个**应对**，而不是整句。但那句 `FIXED`（那碗面泡烂在桌上）没用上。**

### C2：台账新增可选字段 `cognition`

```python
# state/ledger.py LedgerEntry
cognition: dict | None = None   # {"op", "quotes", "hint", "yielded"}
```

**★ 为什么必须记 `yielded`：五算子一起上假阳性会堆叠，"哪几个也触发了但被让位"
是事后查假阳性的**唯一依据**。**
**★ 为什么必须记 `quotes`：`C5` 只认这两段逐字命中，台账里要留着当初核对的是哪两段。**

```

**★★ 但实测发现：行 124 其实**不是**假阳性：**

```
