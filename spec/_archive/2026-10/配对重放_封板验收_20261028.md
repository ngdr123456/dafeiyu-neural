# 24 轮配对重放（封板验收）· 2026-10-28

> **性质**：Gemini 第四封第 1 步的验收实验。**判据先写、后看数据。**
> **成本**：24 轮｜661 秒｜均 27.5 秒/轮（约 3–4 次 API 调用/轮）
> **工具**：`tools/配对重放.py`｜明细：`spec/配对重放_20261028.jsonl`

## 零、为什么用配对重放而不是跑 `train.py`

**Gemini 查清了上次 78% 被污染的原因（我复核代码，成立）：**

```python
# train.py:481-484
usable = [s for s in sequences if len(s["turns"]) <= session_len]
picks = list(rnd.choice(usable)["turns"]) if usable else []
while len(picks) < session_len:
    picks.append(rnd.choice(pool))
```

**`sequences.json` 每条恰好 3 轮；`--session-len 3` ⇒ `picks` 一上来就被填满，**
**`while 3 < 3` 一次都不执行 ⇒ **100% 抽到 S01–S05**（押金/楼层）。**

**⇒ 配对重放：输入固定为 `eval.jsonl` 第 191–214 行的**真实家教原话**，只换系统。**

**数据集结构：12 个 2 轮会话（其中 6 个的 session_id 为 None，6 个为 0/1/2 ×2）。**

| 指标 | 旧 | 新 | 判 |
|---|---|---|---|
| **① META 劫持率** | **11/24 = 46%** | **0/24 = 0%** | ✓ **决定性** |
| **② 长陈述回声率** | 2/24 = 8% | 2/24 = 8% | ⚠️ **没变（分母塌缩，见下）** |
| **③ 精准锚点追问率** | 0/15 = 0% | 2/13 = 15% | ⚠️ 低（指标失效，见下） |

### ★ 但还有三个他没列的指标，变化很大

```
输出含问号       旧 **5/24** → 新 **15/24**（3 倍）
输出长度中位     旧 **44 字** → 新 **21 字**（减半，符合 FRAME 第 6 条「说短」）
UNCLASSIFIED     新 **5/24 = 21%**（改动前实测 83%）
```

## 二、② 为什么没变：**分母塌缩**

**② 的定义是「非问句 且 >18 字 且 新词占比 ≤0.30」。**

```
旧：24 轮里只有 5 轮含问号 ⇒ 19 轮进分母 ⇒ 2 条命中 = 8%
新：24 轮里有 **15 轮含问号** ⇒ 只剩 9 轮进分母 ⇒ 2 条命中 = 22%（按新分母算）
```

**⇒ 把 ② 从"占全体"改成"占该进分母的轮次"：旧 2/19 = 11% → 新 2/9 = 22%。**

**⚠️ 但这两个分母都太小（19 与 9），按纪律只能写「线索」，不下方向结论。**

**★★ 正确的说法：**② 的绝对条数没变（2 → 2），但它**所衡量的那类轮次本身少了 10 轮**
（因为有 10 轮从"长陈述"变成了"问句"）⇒ 用"占全体"来比是**指标定义掩盖了变化**。**

---

## 三、③ 为什么低：**指标测的不是她实际抓的东西**

**③ 要求：抽出 `anchor` 的轮次里，输出**逐字含 anchor** 且（问句 或 ≤18 字）。**

**实测抽出的 anchor 大量是 `''`、`'他'`、`'那天'`、`'电脑桌'` ——**
**而她实际抓住的具体物是：**

```
「第一是谁」    ← anchor 抽到的是空
「后头」        ← anchor 抽到的是空
「再试最后一次」 ← anchor 抽到的是空
「删了又打的那几遍」← anchor 抽到的是 '那天'
```

**⇒ 她抓住的具体物多数来自 `concrete` 或模型自己，不是 `anchor`。**

**⇒ **指标失效的原因是抽取器，不是她的输出。** 这一点和上次"78% 测不出来"同源。**

## 五、封板判决

**Gemini 的指令：跑完这 24 轮，看到 META 劫持率和长陈述回声率降下来之后，**立刻封板**。**

**实际：**
```
META 降了 ✓（46% → 0%，决定性）
长陈述回声率：绝对条数没变（2 → 2），按修正分母是 11% → 22%
```

**⇒ 我判：**这一层该封板，但理由不是"回声率降了"，而是：**

```
① META 短路修好了（这是机制层通电的前提，必须做且已做）
② 问句 5→15、长度 44→21 —— 行为形态明确了
③ 剩下的 3 条模板复述，靠改 _pick_anchor / 调字数**治不了** ——
   因为它们走的是模板路径，不是生成路径
⇒ 继续在这一层打磨的边际收益确实见顶
```

**⇒ 同意封板。此后不再在"抠名词正则"和"调 18/20 字"上改。**
