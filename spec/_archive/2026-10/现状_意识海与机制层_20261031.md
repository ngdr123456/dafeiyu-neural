## 二、机制层（"神经模块仿真"）：**是标记计数的工程代理，不是神经仿真**

### 它实际是什么

```
engine/mechanism.py   1160 行
step(markers, raw, channel, context_key, stem_level, engaged) -> MechanismState
```

**⇒ 输入只有：**词表命中（markers）+ 原话长度 + 通道 + 上下文键 + 种子水平**。**
**⇒ 输出：**动力量 w / 偏好 l / 增益 a / 通道压力 e / 张力 tension / 相位 phase / 未完成量 unfinished。

**★★ 关键事实：它**完全不读** cognition 的产出。**
```
mechanism.py 里检索：
   cognition   **不读**
   claims      **不读**
   WANT_MUST   **不读**
   COST_FEEL   **不读**
```

**⇒ 所以"意识海"和"机制层"目前是**两条平行线**，只在 `_build_frame` 的简报里汇合。**

### 我对"神经模块仿真"这个说法的诚实评价

```
· 它**不是**神经仿真：没有神经元、没有群体编码、没有可塑性规则
· 它是**标记驱动的状态机**：给定词表命中与字数，按写死的公式推进一个 4 维读数
· 代码里自己写着「工程代理读数（不是生理测量或主观体验）」
  ⇒ 我认为这个自我标注是准确的，不该被叫成"神经模块仿真"
```

### 唯一"从经历生长"的东西：boldness

```
boldness 是机制层之外、由遭遇逐步累积的唯一量：
  CONFIRMED +0.03｜REBUFFED -0.06（受挫权重是确认的两倍）
  每步 clamp，有界状态机

实测：0.50 → 0.56 / 0.89 / 1.00（多批顶到天花板）
⇒ 它**会动**了，但**会饱和**；而且我们已经决定**暂不作为任何行为规则的依据**
```
