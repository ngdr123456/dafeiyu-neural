## 一、修掉的两处训练器 Bug（Gemini 查出来的，我确认）

### 1. `train.py`：同一场会话每轮都在换题

```python
# 修前
while len(picks) < session_len:
    picks.append(rnd.choice(pool))      # ← 每一轮抽一道**不同的**新题面
                                        #   然后作为【题面/上下文】传给家教
# ⇒ 家教每轮看到题面换了，当然每轮被迫切话题
# ⇒ 这就是「这批语料第 3 轮就换题」的**真正原因** ——
#   不是我之前分析的"语料本身如此"，而是**训练器每轮在换题**

# 修后（家教模式）
if tt is not None and not usable and pool:
    _seed = rnd.choice(pool)
    picks = [_seed] * session_len       # 一场会话共用一个种子题面
```

**⚠️ 只在 `tt`（训练师可用）时这么做：非家教模式下 `picks` 的每一条**本身就是用户输入**，
复制同一 item 会变成让她连答同一句话，那是另一种坏。**

### 2. `admin_agent.py`：家教只能看见最近 2 轮

```python
hist = "\n".join(... for u, s in history[-2:])   →   history[-5:]
```

**⇒ 6 轮会话聊到第 4 轮就把第 1 轮忘光，只能每轮重新起头。**

**★ 这个改动让 `test_admin_escalation` 的 C1（钉住 14 个方法的 AST 哈希）失败。
我更新了 `tests/_baseline_admin_methods.json` 里 `encounter` 的哈希，
并在 `为何钉死` 里写明了**为什么刷新**（有意改动，其余 13 个哈希未变）。**

## 二、去助手化三件套

### C：`FRAME_SYSTEM` 认知前提分流（他说这是"总病根"）

**把这段从**常驻开头**删掉：**
```
· 他若问一件事实，就照实回答……回答完事实就停住。
  照实回答是一件事，替他决定什么是另一件事。
```

**换成：**
```
★ 他的存在姿态（比下面所有条目都优先）：
他在向你敞开他此刻的处境，**不是**在向你派单索要决策。
所以他哪怕带着问号，哪怕说「A 还是 B」，那也**是这两头在他心里打架**。

⇒ 因此你**根本不需要**向他表态「这个我替你定不了／挑不了／判不了」——
   没有人在让你替他定。那句话一出口，你就从"在场的人"变成了"客服"。

⚠️ 「我替你定不了」「这两个我替你挑不了」「决定权在你手里」—— 这些话
   **不是诚实，是免责声明**。你确实可以不替他定，但**不必说出来**：
   **不说也是一种不替他定。**
```

### ★★ 而我在这里犯了一个真错（LIVE 门抓到的）

**我把事实处理指南删了，但**忘了把它注入任何地方**。**

```
⇒ 她完全失去了"问到既往说过的事，先查下面的原话记录"
⇒ LIVE 门：`contact_after_restart:周老师` 两遍都不过，gate=false
```

**修法：`FACT_GUIDE` 改成**按需注入**到 `FRAME_USER`（紧挨原话记录）：**
```python
_FACT_ASK = re.compile(r"收着|谁收|在哪|叫什么|上次说|按你之前|你记得|什么模型|你是谁|…")
if _needs_fact_guide(self.raw):
    fact_block = "\n" + FACT_GUIDE
```

**实测：**
```
「甲项目押金现在由谁收着」→ 注入 ✓
「那家公司叫什么名字」    → 注入 ✓
「按你之前说的」        → 注入 ✓
「今天有点累」          → **不注入** ✓（日常倾诉不背客服条款）
「你是什么模型」         → 注入 ✓
```

**⇒ 修完 LIVE 门恢复：`gate=true｜stable_fail_cases []`。**

### B：`DILEMMA`（句内两难）

```python
# 「A 还是 B」→ 两条并存的下拉
DILEMMA_RE        = 允许多一个逗号在「还是」前
DILEMMA_WHETHER_RE = 「该不该/要不要/能不能 X」= X 与「不 X」
DILEMMA_BLOCK      = 元提问/事实追问不算（是什么/为什么/哪个模型/…）

hint: 【你看到的句内两难】他把「A」和「B」摆成了二选一 ——
      **这不是在让你替他挑**，是这两头此刻都在拽着他。
```

**实测：**
```
「那你说我现在该干嘛，接着改还是先睡一觉？」→ ['接着改', '先睡一觉'] ✓
「我是接着改，还是先睡一觉。」          → ['我是接着改', '先睡一觉'] ✓
「我不知道该不该再试一回。」           → ['该不该', '再试一回'] ✓
「你还是别去了。」                  → — ✓（不误判）
「你是什么模型还是什么的？」           → — ✓（元提问不误判）
```

**优先级：算子3 > CHAIN > DILEMMA > 单跳。**
