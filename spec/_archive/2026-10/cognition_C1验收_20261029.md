## 三、★★★ 关键发现：**分类稳定，不稳定的是召回**

**第一轮我把丢弃的 191 条按原因拆开（这是整轮最有价值的发现）：**

```
missing_in_one_pass（一遍有、一遍没有）：**183 条 = 96%**
   ACTION 72｜WANT_MUST 44｜COST_FEEL 34｜FIXED 33
kind_disagreement（两遍都抽到、但**分类不同**）：**8 条 = 4%**
   COST_FEEL/FIXED 4｜ACTION/FIXED 4
```

**第二轮（并集规则）复核：716 条里去重后 508 条，`kind_disagreement` 仍只有 **8 条 = 1.1%**。**

**⇒ 所以：**

```
分类**不摇摆**（真分歧 1.1%）；摇摆的是**这一遍抽不抽到**（重复率 29%）。
⇒ 不稳定的是**召回**，不是**判断**。
```

**★★★ 这推翻了我在申报单里报的风险 ① 的严重程度：**

```
我原来担心：「label 不可验 ⇒ 分类会摇摆 ⇒ 算子会想错」
实测：分类很稳（1.1% 分歧）；风险①的真实形态是「召回不全」，不是「判断错」
⇒ 缓解措施从"要求两遍都出现"放宽到"只丢真分歧"，是对的
```

## 五、判据 ③：抽样（人眼看准不准）

**抽到的样本（第一轮，结构相同）：**

```
行 0  「我也知道这么想不对，可你让我放下……我试过，第二天整个人跟丢了魂似的，饭都不想吃。」
      ACTION     '我试过'
      COST_FEEL  '第二天整个人跟丢了魂似的'
      COST_FEEL  '饭都不想吃'          subject='饭'

行 1  「就那个offer啊……也不全是。我妈昨天打电话问我"最近怎么样了"，我说挺好的…」
      ACTION     '我说挺好的'          subject='我妈'

行 2  「那你要我怎么说，跟她说我连个offer都拿不到、在家瘫着？…」
      COST_FEEL  '在家瘫着'
      COST_FEEL  '我就是不知道挂了电话以后该干嘛'  subject='挂了电话'

行 3  「……是那半个钟头吧，电话里我还能顺着她，挂了以后就没人可说了。
        对面楼那排灯一盏一盏灭，我就站那儿，也不知道在等什么。」
      COST_FEEL  '也不知道在等什么'
      ACTION     '我就站那儿'
```

**★ 我的判断：大部分准。**"我试过""在家瘫着""我就站那儿"确实是行动或退缩；
"跟丢了魂似的""不知道在等什么"确实是代价。

**★ 两处明显不对（已在下面第六节记为待修）：**

```
· `subject='饭'` 对「饭都不想吃」—— 对象应是"吃饭"这件事，不是"饭"这个物
· 「我就是不知道挂了电话以后该干嘛」判 COST_FEEL —— 那更像 **ACTION 的缺失**
```

## 七、第 2 步之前建议先修的两处（小改，可并入第 2 步）

```
① subject 粒度：要求 subject 是**名词短语**而不是单字（"吃饭"而不是"饭"）
   ⇒ 一行校验：len(subject) >= 2（单字 subject 清空）
② ACTION 的缺失 ≠ COST_FEEL：「我就是不知道…该干嘛」「没开口」「没去」
   ⇒ 在 prompt 里给 ACTION 加一条线索：「**没做**也算 ACTION（没开口／没去／忍住了）」
```
