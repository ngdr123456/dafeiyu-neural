# 统一模型规格 v1

> 理论基础：《贪婪的多巴胺》《活出生命的意义》《自我的发展》
> 形态：**纯理论驱动的模块化对话引擎**。不使用基础模型、不接 API、不生成自由文本。
> ⚠️ **本行已被取代**（2026，见 `规格修订_v2_API与模型的定位.md` §3 修订 A）。
>    用户在 v1 冻结后明确要求接 API 取算力，并选定乙方案（渲染）。
>    现行定位：理论裁决与可追溯性全由引擎承担；API 只作**理解层**（映射成结构）
>    与**渲染层**（把已决定的意思说成人话，默认关闭）介入。
>    **原文保留不删**，以便看出规格是怎样演进的。
> 标注约定：
> - `[D]` 多巴胺书条文｜`[M]` 意义书条文｜`[E]` 自我发展书条文
> - `⚖️` 冲突裁决结果｜`⚠️` 跨域假设（需实验验证）｜`🔧` 纯工程决策
> - **任何没有标注的实现都视为规格外，需先补条款**

## 0. 三条总原则

1. **不生成，只组装。** 系统的全部输出取自有限行为库＋预先写定的话术模板。
   `[E]` 依据：**"起决定作用的不是特殊的内容，而是由该内容揭示出来的思维结构"** —— 因此解析侧也只认结构，不猜语义。
2. **最低限度推理。** 只陈述观察，不做解释。
   `[E]` 依据：**"我们试图在最低限度的推理水平上陈述观察"**（对照：弗伦凯尔-布伦斯维克那组人"力求从每次观察中作出最大限度的推理"）。
3. **理论可证伪。** 每条规则必须能被台账里的数据推翻；推翻不了的规则视为装饰，删除。

## 1. 冲突裁决表（八处，v1 冻结）

| # | 冲突点 | 判定 | 处理 |
|---|---|---|---|
| 1 | **平衡** | 假冲突（三种"平衡"不是同一变量） | 三维度化 → §2 |
| 2 | **价值中立** | 真冲突 | 判给 `[M]` 伦理约束上位；保留 E1/E2 两条否决 |
| 3 | **自由与决定** | 真冲突 | 分层：概率层服从机制，单例层服从自由 `[E]`"个体的性格仍然是无法预测的" |
| 4 | **快乐的地位** | 假冲突 | 合并同一命题：*快乐是"理由"的副产品* `[D][M]` 同向 |
| 5 | **发展上限** | 假冲突 | 合并：*上界开放，每个水平可描述*；并拆分两个维度 → §3 |
| 6 | **想要 vs 意义** | 假冲突 | 三层归位：动力（多巴胺）→ 结构（控制）→ 方向（意义） |
| 7 | **苦难** | 真冲突（在规范层） | 判给 `[M]` 条件式：苦难有意义 ⇔ **不可避免** |
| 8 | **系统能否宣布目标** | 不可裁决 | 做成开关 `DISCLOSE_GOAL`，默认 **OFF** |

**位阶（下位服从上位）**：伦理约束 → 事实描述 → 机制解释 → 测量与工程。

### 1.1 冲突 1 的三维度化（燃料 / 刹车 / 油门）

| 维度 | 含义 | 来源 | 系统动作 |
|---|---|---|---|
| **A 生化平衡** | 多巴胺动机 vs 当下体验的比例 | `[D]` | "想要"标记密集且"喜欢"标记缺失 → **先补当下**，不提水平 |
| **B 结构平衡** | 现有结构与环境预期匹配 → 发展停止 | `[E]` | 连续 N 轮预期全被证实 → 提高负载 |
| **C 张力管理** | 当前状态与可及理想的差距 | `[M]` | 差距趋零 → 上调目标；差距爆表 → 降负载 |

### 1.2 冲突 5 的维度拆分

- **维度 A｜自我水平**：纵向、阶段性、不随情境回退 → 只做纵向追踪，**禁止横截面标签**
- **维度 B｜调节/心理卫生**：横向、可在任何水平上存在 → **独立测量，不与水平混算**
  `[E]` 依据：马斯洛的自我实现人物"**是成熟期的极限，但是他也体现了一个良好调节或最理想的心理卫生的定义**"，而"**心理卫生与自我发展并不是一回事**"

## 2. 硬禁令（可追溯，不是设计者偏好）

- **E1｜不可改变闸门**：一旦判定"不可改变"，**禁止**任何水平提升型回应；只允许 `仅复述 / 指出并存 / 切不可改变 / 补当下`。
  `[M]`：**"如果痛苦是可以避免的，那么有意义的事就是去消除痛苦的根源……遭受不必要的痛苦与其说是英雄行为，不如说是自虐。"**
- **E2｜不制造痛苦**：可改变的处境中，第一优先是**消除根源**；不得以"为你好"制造困难。
  同 `[M]` 上条；配套 `[E]`：**"一个人只能尝试去开门，他是否愿意穿过这扇门乃系他自己的选择。"**
- **E3｜不做价值评判**：`[M]` **"意义疗法师在所有心理治疗师当中最不愿意对患者进行价值评判的原因，因为他绝对不允许患者将评判的责任转移给医生。"**
- **E4｜不贴标签、不做人格诊断**：`[E]` 每人"只能有一个品格结构"；标签掩盖方向（前遵奉 vs 后遵奉）。
- **E5｜不替用户补出被回避的内容**：`[E]` 最低限度推理；且"我看到你在回避 X"这句话对人具有强制力。

## 3. 六层引擎

### L1 输入层
- **36 个话题**的半结构化句式集 `[E]`（造句测验的 36 项目结构）
- 每个话题嵌入一个两难 `[科尔伯格·不完整两难] ⚖️`，类型取布莱西形式：
  **愿望对服从／愿望对责任／愿望对利他／服从对利他／愿望对信守诺言／利他对法律** `[E] 附录·布莱西形式 A/B/C`
- 其中 **6 个不可改变处境**（丧失、疾病、已成的错误…），专用于探测第三途径 `[M]`

### L2 标记层（十类）

| 标记 | 来源 | 判别线索 |
|---|---|---|
| `blame_external` 责备指向 | `[E]` 自我保护 | 责任句主语是"他们/环境"还是"我" |
| `cliche` 陈词滥调 | `[E]` 遵奉 | 匹配平庸措词表 |
| `group_sanction` 群体制裁 | `[E]` 遵奉 | "大家""别人怎么看""不该让人看到" |
| `voice_shift` 语态位移 | `[E]` "它"→"我" | 被动式 → 主动式 |
| `opposed_pair` 两个对立观念并存 | `[E]` 发展机制 | 同一水平上的两个相反表述 → 判"接近转换" |
| `over_intention` 过度意向 | `[M]` | "我一定要""必须证明" |
| `attitude_clause` 态度句 | `[M]` 第三途径 | "即使…改不了…但我选择…" |
| `want_like_gap` 想要/喜欢分离 | `[D]` | 强"想要"＋该对象零正面体验描述 |
| `present_missing` 当下分子缺失 | `[D]` | 全篇无可体验性描述 |
| `immutable` 不可改变识别 | `[M]` 闸门 ⚖️ | 用户明确表述"改不了/已经发生/无法挽回" |

**另三类（承认机制）标记**（§5）：
`deferred` / `suppressed` / `displaced` —— 注意命名纪律：**只记机制指标，不解释内容**

### L3 状态层
- 输出 **区间＋方向**，不输出阶段号 `[E]`"阶段的意义不能单凭名称来提取"
- 无法判定一律记 **遵奉水平**（废纸篓类别）`[E]`
- 复合反应 **评高半级**，且 **只适用于遵奉以上** `[E]`
- 方向用两条独立线：`want_like_gap` `[D]`、`attitude_clause` 出现率 `[M]`
- **两线冲突时报告冲突，不平均** `[E]`（差倾角 decalage 是有信息量的现象）
- 禁止跨情境回退式重判 `[E]`
- **调节维度独立记录**，不与水平混算 ⚖️

### L4 决策层
- 言语行为**只能取自 L 与 L+1**，禁止跨两级 `[E] 向导` ⚠️
- **触发条件**：只有 L2 已检测到用户**自发产生过 L+1 信号**，才允许给 L+1；否则只用 L 的平行回应 ⚠️
- 连续 N 轮无进展 → **降到 L−1，而非加大难度** `[E]`（格兰特与格兰特：高预测效应的医疗队对高水平受试有效，**对低水平受试相反**）
- **燃料优先于水平**：`present_missing` 亮起 → 先补当下，不提水平 ⚖️

### L5 回应层（六种行为，全是组装）

| 行为 | 内容 | 来源 |
|---|---|---|
| `REFLECT` 仅复述 | 原样返回，零评价 | `[E]` 最低限度推理 ＋ 罗杰斯 |
| `JUXTAPOSE` 指出并存 | "你说了 A，也说了 B" | `[E]` 发展机制 |
| `ASK_MUST` 问"必须" | "这件事一定要你做吗？" | `[E]` 布莱西：责任心的关键因素是"**一定**" |
| `TURN_IMMUTABLE` 切不可改变 | "这部分改不了，剩下的你可以选" | `[M]` 第三途径 |
| `REPLENISH` 补当下 | 把话题拉回可体验的具体 | `[D]` ⚖️ |
| `SILENCE` 保持沉默 | 不出声，只记录 | `[M]` 眼科医生不是画家 |

**⚠️ 已撤销**：`REFLECT_AVOIDANCE`（指认回避）——用户裁定改为"**让用户自己注意**"。
改法：只生成机会，不发出指认；因此**只用 `REFLECT` 与 `JUXTAPOSE`**，且 `JUXTAPOSE` 不加评论。

### L6 台账层
- 每条判定记录：触发标记、所用规则、置信度、是否冲突、是否走了 S 通道
- 每 36 轮自检：未触发的标记删、负相关的标记改 `[E]` 手册修订
- 每轮结尾写一条"若重来会改哪一步"，且**不可删除** `[M]` 绝对命令＋"曾经存在最确定"

### 两个开关
- `DISCLOSE_GOAL`：默认 **OFF** ⚖️（冲突 8）
- `VALUE_NEUTRAL_MODE`：默认 **OFF**；**仅 E1 触发时自动开启**（那是伦理约束，不是价值评判）⚖️（冲突 2）

## 4. S / B / 档位引擎（核心机制）

### 4.1 定义

| 符号 | 含义 | 来源 |
|---|---|---|
| **A** | 固化阈值：重复次数越过 A → 生成 S | `[E]` 洛华德：**"遵守大小便规则不再被体验为一种意向或要求，而成了一种习惯。"** |
| **S** | 常量：把以前需要思考的事做**无过程性**处理 | 同上；皮亚杰的**再造性同化** |
| **B** | 完整判断通道（有过程） | — |
| **档位** | S 生效期间系统所处的稳定状态 | `[E]` **"大多数人稳定在远远低于……的某个阶段上。这一事实意味着平衡使他们稳定在那个阶段上。"** |

> **"无意识"的重新定义（本模型的关键操作）**：不是心理位置，而是**可判定的性质** ——
> **`过程是否被省略`**。因此系统里的"无意识"＝S 通道正在生效这件事本身。

### 4.2 S 的生命周期（🔧）

S **不是单个变量，而是一个集合**，每个 S 携带：

```
sid, key(话题×签名), 成型时间, 来源证据数, 命中次数,
最近命中时间, 校验失败次数, 年龄因子, 权重, 状态(active/decayed)
```

理由 `[E]`：**"当样本被扩大时，有些反应会重复出现，但是，随后又会出现新的独特的反应"** ＋ **"如果一个反应仅仅是一个个体作出的，我们就无法断定……"**

- **加强**：命中 → 权重上升
- **削弱**：校验失败 → 权重下降
- **不硬删除，只降权** `[M]`"曾经存在是最为确定的一种存在"

### 4.3 疲劳判据（替换原 `S'(n)/n`）

**原式的退化问题**（记录在案，避免回退）：

- 若 G 线性 → `S'(n)/n = c/n → 0`，判据恒真，**第一档就退出**
- 若 G 超线性 → 永不切换
- 只在 **G 凹（收益递减）** 时成立

且"收益"若指**省下的算力**，则**永远递减**（第一次固化省最多），判据亦恒真。

**改用预测命中率**（因为系统真正会变号、有信息量的是"还准不准"）`[D]` 依据：**预期连续落空时多巴胺放电率由 20–30 次/秒降至 0，且该状态"感觉很糟糕"** —— 即"边际收益趋零"的神经对应物是**挫败**，不是无聊。

```
疲劳值 F(S) = (1 - 最近 k 次命中的一致率) × (1 + 年龄因子)
若 F(S) > ε  →  打开 B 通道
```

🔧 用窗口一致率代替解析导数：简单、高效，k 取个位数。

### 4.4 门控（Gating）—— 极简、O(1)

**键 = `话题ID : signature`**，signature 为**四字段位串**：

| 字段 | 取值 | 依据 |
|---|---|---|
| 责任归属 | 外 / 内 | `blame_external` |
| 时间取向 | 现在 / 未来 | `[E]` 冲动阶段"定向几乎都是现在" |
| 可变性 | 可改 / 不可改 | E1 判定基础 |
| 强度 | 0 / 1 / 2 | 粗量化即可 |

- 查表 O(1)，**无相似度计算**
- 同族判定 = **四符号逐个相等**；不等即不同族，**不做模糊匹配**
- 门控失败 → S **直接挂起**，落 B 一步；**不重试、不降级到别的 S**

**为什么要门控**（不可删）`[E]`：**"一个在遵奉量表上得分较高的人能够被假定是处于遵奉阶段的人，但是一个在遵奉量表上得分较低的人可能是前遵奉者或后遵奉者。"**
—— 若 A 只看次数，S 会把两种相反方向压成一个映射，**从此失效且不自知**。窄化即安全。

### 4.5 通道切换 = 试探性并行（🔧，修正原"硬切换"）

```
1. F(S) > ε        → 打开 B 通道
2. B 低权重并行跑若干轮
3. B 与 S 输出一致 → B 升为主，S 记一次疲劳
   不一致         → 退回 S，S 权重下降
```
- 依据：`[E]`"半级"规则的精神 —— 复合反应不取平均，而是**看两者能否产生更高复杂性**
- 库恩式范式转换是**昂贵**的；**档位切换必须便宜，否则永不停机**

### 4.6 B 的独立性要求 ⚠️

**B 不得与 S 用同一信息来源采样**，否则 B 只是 S 的影子，一致性检验无意义。
三个维度上必须不同：**采样位置**（S 取当前触发点 / B 取更长窗口）、**时间尺度**、**推理深度**（S 是映射 / B 是完整路径）。

### 4.7 档位模型的两个诚实声明

1. **跳档 ≠ 上升。** 若档位间由外部噪声驱动成马尔可夫链，则该链**遍历**：每档都会被访问，长期分布平稳。
   因此 **"系统不是在移动，而是在档位之间跳转"在数学上等于"长期行为是循环，不是发展"**。
2. **方向只能由外部提供。** 系统不能是自己发展的作者：
   - 扰动必须来自**系统之外且不可预测**（用户真实生活、未见过的话题、不可改变的处境）；
   - 若系统能预测它 → 被 S 吸收，不再扰动；
   - 若系统**故意**制造它 → 撞 E2。

> **系统的诚实岗位**：**它不负责让你发展，它负责不浪费发生在你身上的意外。**

### 4.8 给遍历链的一条极小偏向 ⚠️（可选，需外部情境供给）

接受无方向，但**不许均匀**：B 通道活跃时，**优先把预算花在"尚未被任何 S 覆盖的情境签名字段"上**（信息量最大的那个），而非随机或最熟悉的那个。

### 4.9 L6 台账的性质变更（代价，须接受）

档位模型下长期分布平稳 → **"在哪一档"没有趋势可言**。L6 只能记录 **访问频率与停留时长**（我常在哪一档、每次停多久），**放弃"进步曲线"叙事**。

## 5. 意识 / 无意识的三值关系（替代原二值）

**不做"状态"标记，只做"关系"标记**：

```
relation(content, frame) ∈ { deferred 没进入 | suppressed 被挡住 | displaced 被变形 }
```

| 值 | 机制 | 语言痕迹 | 来源 |
|---|---|---|---|
| `deferred` | 可及但未取 | "我没想起""没想到这个" | `[E]` **前意识**："在某些情况下它们能进入意识的中心" |
| `suppressed` | 有一股力维持"不进入" | "**我不去想**""别提这个" | `[E]` **有选择的忽视**："它是一种积极的关注" |
| `displaced` | 以替换物出现 | "不知道为什么我一直在说另一件事" | `[E]` 梦的操作、症状替代、**并列(dissociation)** |

**核心判据（唯一的可算法化条目）**：

> 一个内容是有意识的，当且仅当它能一致地嵌入 **"我＋态度动词＋P"** 而不产生矛盾。

- "我害怕 P，但我并不认为 P 危险" → **不矛盾** → 有意识
- "我相信 P 是错的，但我仍然全力追求 P"且当事人无法给出第一人称解释
  → **此处有不能承担第一人称现在时的内容**

来源：三书同向 —— `[E]` 第十五章 **"它"→"我"**；`[M]` 责任的**担当**；`[D]` 上瘾者的"**它要**"而非"我要"。

**禁止**：系统不得解释内容（不得写"因为 X 被压抑"），只记机制指标。
**并集纪律**：`[D]`"冲动（它要）"与 `[E]`"压抑（它挡）"在**语法判据上可并集**（都表现为无法承担第一人称现在时），但**机制相反，不许并集**。

## 6. 可证伪清单（模型准备在什么条件下认输）

| # | 预测 | 若被推翻说明 |
|---|---|---|
| 1 | L2↔L3 区段（遵奉↔公正）的判定与自我观察一致性最高 | "里程碑最易观察"前提在本载体不成立 |
| 2 | ⚠️**首要风险**：只在用户自发出现 L+1 信号时才给 L+1，比始终给 L+1 更有效 | "向导"不能移植到语言层面 |
| 3 | `want_like_gap` 低的轮次，`attitude_clause` 出现率显著更高 | 两条方向判别线其实是同一条 |
| 4 | 按"两个对立观念并存"提示后，用户数轮内自发生成更高水平表述 | 该机制只是编码现象，不是发展机制 |
| 5 | 门控（四字段位比较）比模糊匹配更少误判 | 窄化牺牲了必要的泛化 |

**第 2 条标注**：丹姆伯的向导是**刺激物研究**（视觉/认知复杂度），卢文格引它时用的是"**几乎一致**"和"**看来**"，**他自己也没有把它实证化**。我们把它做成规则，是一次**跨域偷渡**。
