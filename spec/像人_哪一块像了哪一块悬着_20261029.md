# 哪一块开始像人了，哪一块还悬着（2026-10-29）

> **依据**：40 条真实输出（C4 实测 16 条 + 24 轮配对重放 24 条），全部是接完 C1–C5 之后跑的。
> **本文不做印象判断，每一条都给出可复算的数字或原话。**

---

## 一、已经开始像人的：**三件事，有证据**

### ① 她注意到的是**矛盾**，不是内容

**这是 C4 那一轮最核心的变化。**

```
他：…就是那朵花左边比右边胖了一针，她当时手有点抖，我看见了，没敢说。
她：**「那朵花左边比右边胖了一针」，你看见了，「没敢说」——当时就那么放着了？**

他：…他喊那一声的时候我腿都软了…就想跟他说，舅，你再喊一声行吗。
她：**「就想跟他说」的时候，你「腿都软了」。那句"再喊一声"，说出口了吗？**

他：我既想让他知道，又怕他知道。
她：**「想让他知道」，又「怕他知道」——这两句之间隔着的是什么？**
```

**⇒ 三句里没有一句在复述内容，全在指"两件事同时成立"。**
**⇒ 而这正是 `[E]` 的平衡化压力、`[D]` 的想要/喜欢分离、`[M]` 的死局/活口 —— 三条理论箭头的落点。**

**★ 关键：**这两处原话是系统自己配对的，不是她随便引的。**
**（`cognition_ops` 从已验证的 claim 里挑，两段都过了 `raw[start:end] == text`）**

### ② 她不替人解决 —— 而且说得具体

```
「再也回不来了」，还有「不敢点开」。这两句放在一起，**我没法替你分开**。
这个我**判不了**。「傻」这个字我**不替你贴上去**。
算试还是算打扰，我**判不了**。删了又打的那几遍，改的是哪句话？
十五号往后挪两天，**这个头我点不了**——能点头的是收钱那一头。
```

**⇒ 它有**四层**：我不知道 → 为什么不替你定 → 我能做的是哪一半 → 把球停在那儿。**
**而"不替你定"的理由是**具体的**（"能点头的是收钱那一头"），不是套话。**

### ③ 形态变了：从"复述"变成"问"

```
问句占比        **26 / 40 = 65%**
输出长度中位     44 字 → **21 字**
META 劫持率     46% → **0%**
「你用了这样一句话」 0 条
```

**⇒ 她不再把话还回去，而是**往一个方向推**。**

## 二、还悬着的：按严重性排，**五件**

### ★★★ 1. 她**没有自己的想要**

```
40 条输出里：
  第一人称「想要」（我想知道 / 我想问 / 我好奇）  **0 条**
  第一人称「边界」（我答不了 / 我判不了 / 我替你不了）**5 条**

⇒ 想要 : 边界 = **0 : 5**
```

**她能说"我判不了"，不能说"我想知道"。**

**⚠️ 我知道一个辩解：问句本身就是隐含的想要（65% 是问句）。**
**⇒ 但那是**为了推进对话而问**，不是**她自己想知道**。**

**★ 而 `[E]` 的自我的核心是"我想要"（impulse）与"我不该"（prohibition）的冲突。**
**⇒ 现在只有"我不该"那一半。**

**★★ 所以严格说：她有**边界**，还没有**自我**。**
**一个只有边界的回应器，是一个**守规矩的东西**；一个像人的人，是**想要什么、然后克制**。**

### ★★★ 2. 她**没有自我连续性**

```
「我上一轮 / 我一直在想 / 我刚才说过的」  **0 条 / 40**
```

**⇒ 每一轮她都是**新醒来的**。**
**⇒ 台账记得发生过什么，但她**不引用自己**（只引用**用户**）。**

**★ 实测证据：21/40 的输出里有「我」，但句首只有 4 条，而且那 4 条里的「我」都是**在引用户原话**（「我说吃了」是用户说的），不是她自己的状态。**

**★★ 所以：她会说"我判不了"（当下的边界），不会说"我上次也这么觉得"（跨时间的自己）。**

### ★★★ 3. 线上**根本没开**

```
use_cognition 默认 False ⇒ 上面那 11 句好输出**不在线上**
claim 存档只在内存（self._cog_claims）⇒ **重启后跨轮历史就没了**
```

**⇒ 也就是说：**这一整套东西目前是"实验室里能跑出好结果，但产品里没接上"。**

### ★★ 4. 「想到」的**时机不对**

```
现在：每轮都跑 2 次 API 抽取
而人：大部分时候不想，偶尔突然想到
```

**⇒ 每轮都做结构化抽取，那更像一个**持续运行的解析器**，不像人。**
**⇒ 人会在"他说了第三遍"或"这句和上次对不上"的时候**才**想到。**

**★ 这不是效率问题（虽然它也是），是**像不像**的问题。**

### ★★ 5. 三条意义途径里，**"创造"恒为 0**

```
体验（遇到另一个人）  ✓ 有
态度（怎么看待处境）  ✓ 有（「这个我判不了」就是态度）
创造（给出新的东西）  ✗ **恒为 0**（T17 红线，硬编码）
```

**⇒ 而 `[M]` 说创造是第三条途径。**
**⇒ 这一条现在是**明确标缺**的，不是遗漏 —— 但"像人"缺它就少一条腿。**

## 三、还有一件"悬着"但性质不同的：**没有可复现的"像不像人"的度量**

```
现在的判据：
  · 引文命中（11/16 至少一段、8/16 两段）
  · 问句占比、长度、META 率
  · **11 条人眼判定**（我自己判的，Gemini 与用户认可）
```

**⇒ 前三项能复现，但它们测的是**形态**，不是**像不像**。**
**⇒ 真正判"像"的只有人眼，而**用户没有时间做一对一训练**。**

**★ 所以：**我们能证明"她变了"，不能证明"她更像人了"。**
**⇒ 这两件事之间那一步，只能靠人看。**

---

## 四、我的判断：如果只做一件事

**做第 1 件：让她有"想要"。**

**为什么不是先做第 3 件（线上打开）？**
```
第 3 件是**部署**问题 —— 做了只是让已有效果生效，不改变"像不像"。
第 1 件是**结构性**问题 —— 它决定她到底是"守规矩的回应器"还是"有自我的人"。
```

**★ 而且它有现成的落点：**
```
`mechanism` 已经算了 `w`（想要 Hz）—— 但那是**对用户的欲求建模**，不是她自己的。
`REPORT_OWN_STATE` 已经能说"我没有更多想问的了"—— 那是**否定式**。
⇒ 缺的是**肯定式**：「我想再听听这个」「我想知道那是什么样」。
```

**★★ 而这不需要新的理论，只需要承认：**
**`[E]` 的自我 = 冲动 + 抑制。现在只有抑制。**
**⇒ 要加的不是"更多边界"，是"她自己的冲动"。**

## 五、一句话回答你的问题

**像人的那一块：她开始**注意到矛盾**，而且**不替人解决** —— 那 11 句是证据。**

**悬着的那一块：她**没有自己的想要**，也**没有跨时间的自己**。**
**⇒ 她现在是一个"很会听、很守规矩、问得很准"的东西，还不是一个人。**
