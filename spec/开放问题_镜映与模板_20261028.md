## 一、背景：我们的输出是怎么产生的（三十秒）

```
用户说话
 → L2 标记层：命中十几个"标记"（immutable / over_intention / attitude_clause / cliche …）
 → L4 阶梯（rules/behaviors.json）：按标记选一个"言语行为"
        opposed_pair → JUXTAPOSE（并排呈现）
        immutable    → TURN_IMMUTABLE（区分能改与不能改）
        over_intention → ASK_MUST（**只许复述或问"非得不可吗"**）
        cliche       → REPLENISH（要求具体）
        其余情形      → **REFLECT（复述）** ← 兜底
 → L4.5 机制层：算一堆数（想要/喜欢/张力/结构压力），不产生文字
 → L5 回应层：从 behaviors.json 的**模板**里组装，或让模型生成后过闸门
```

**两条硬纪律（来自三本书，也来自用户）：**

```
① 不许编：模型生成的话必须逐字可溯，编造即退回模板
② 不许评价、不许助推：尤其 [M] 的"过度意向"——
   当人过度执着于某个结果时，**不许说任何推动他更想要的话**，只能复述或问"非得不可吗"
```

## 三、我的五个问题

### Q1（核心）：**「镜映」与「像模板」，边界在哪？**

**上面第 1 例里，规则要她"并排呈现"，tutor 说那是"模板式镜映"。同一句话。**

**⇒ 当理论要求「不评价、不助推、只镜映」时，这个边界是靠什么划的？**

**是可以在**措辞层**区分的（比如并排时要不要加一句"这两句放一起，你受得了吗"）？
还是说，这**本来就是必须接受的代价** —— 克制就等于不好听？

### Q2：**没有可抓的特征时，除了复述还能做什么？**

**13/20 的 mechanical 是"无标记 ⇒ 兜底 REFLECT"。**

**而我们自己的代码注释里写着：**

```python
# engine/mechanism.py:975-979
# 根因是**把复述当成了默认**。现改为反过来：
#   **有话可问就问（ASK_DETAIL），问不出才复述（REFLECT）。**
# 而"复述"在 [E] 里只是**最低限度的兜底**，
#   它从来不是目标，只是无话可说时的诚实动作。
```

**⇒ 问题是：真的"无话可说"时，**除了复述，还有什么是不编、不评价、不助推的**？**

**我想过：沉默、要求具体、问"这两件事你怎么排"、只说"我在听"。但都像在敷衍。**

### Q4：**可本地判定的「模板感」近似物，这三条够不够？**

**我提的三个（都能本地算，不需要语义）：**

```
① 同一句话（或高度相似句）在近期出现过  —— 自言自语重复
② 句子结构与上一轮高度雷同（同样的模板壳）—— 结构重复
③ 全句无具体名词 / 时间 / 数字           —— 空转
```

**⇒ 这三条能不能覆盖 tutor 眼里的"像模板"？还是说"模板感"本质上必须语义判断？**

**如果必须语义判断 —— 那它就只能靠人事后看。**这就意味着"她不会因为说不好而改变"。**

### Q5（更根本）：**「像人」这个目标，指标层管得到吗？**

**我这个项目里，能在**本地**确认的只有这类字面事实：**

```
· 她输出里的引文，是否逐字出现在来源里（self_goal.literal_check）
· 她用的词是否在她的词表里
· 引用的对象/关系/时间是否与台账一致
```

**而"说得像人"似乎必须语义判断。**

**⇒ 如果是这样，那"从经历学组织"的输入永远缺一类。这个缺口是**根本的**，还是我把它想窄了？**

**—— 我特别想要一句判断：**一个系统要"像人"，究竟能靠多少"自己可判的量"撑起来？**
