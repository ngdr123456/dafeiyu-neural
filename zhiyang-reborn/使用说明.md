# 智阳神传 · 天启

直接双击「智阳神传·天启.html」即可开始游戏，无需安装、无需服务器、无需联网。推荐用 Edge 或 Chrome 打开。成品只有一个 HTML，复制到另一台设备也可以游玩。

## 操作

- WASD / 方向键：移动；手机使用左下摇杆。
- J / 按住鼠标 / 攻击按钮：普攻。默认开启自动普攻与自动瞄准。
- Q、E、R / 1、2、3：三种角色技能。
- 空格：闪避，包含短暂无敌时间。
- F / 「激活祭坛」按钮：清除守卫后点亮祭坛。
- ESC / P / 左上暂停按钮：暂停、保存继续、结算退出。
- 点击大厅顶部的天晶：进入外观商阁。

## 内容

八位神裔各有独立造型、被动与三种技能。六章征途包含不同环境与首领；无尽试炼每三重切换秘境并迎战首领；星野漫游包含三座祭坛、四个宝箱和最终首领；镜像斗场为 AI 战术对决。

每轮战斗可从三项随机赐福中选择一项，可免费重择一次。共 18 种赐福，支持元素、吸血、环绕星刃、爆炸、连锁雷电等构筑。

神裔修炼与九种灵印永久保留。六槽灵印支持重复装备。天晶用于解锁四套通用外观或兑换修炼灵铢；所有资源都可从游玩中获得。

## 存档

进度自动保存于当前浏览器；暂停后选择「保存并回星庭」可保留本次冒险。刷新或重新打开后，可从大厅「继续上次冒险」恢复。点击设置中的「导出」保存 JSON 备份，「导入」恢复跨设备进度。导入前的存档会保留一份可恢复备份。

不同浏览器，以及文件版与服务器预览版，使用各自独立的存档。移动 HTML 文件、更换设备或浏览器前，建议先导出存档。若当前浏览器提供原版 `zyxz_save_v1` 存档，会迁移昵称、基础资源与历史试炼记录；原版存档不会被删除。

## 本地开发

源码包含 index.html、style.css、engine.js、render.js、game.js。

运行 `node verify.cjs` 执行核心玩法验证；运行 `node build.cjs` 重新生成单文件成品。无需 npm 安装。开发预览可在本目录运行 `python -m http.server 8765`。

这是离线单机重制版本，斗场对手由 AI 控制。战绩显示本机真实记录。
