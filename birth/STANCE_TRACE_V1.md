# 立场痕迹 V1（结构化点）

> 立场已有台账，以及台账→开口的最小接线。同一个结构化点重复出现时，立场连续、痕迹可审计、跨场可读。

## 结构与判定

`StanceTrace` 包含 `kind: "kept"`、`point` 和 `why`。点由既有判定生成：`conflict:<冲突标签>` 或 `commitment:<承诺原文截断>`（最多 40 字，超出追加省略号）。本刀不写 `yielded`；留到「交出过的东西该怎么影响下一轮」那一刀。

组织冲突或同场守诺分支判定落到已守过的同一个 point 时，`reasserts_kept` 为 True，原 why 后追加「已经守过，这是第 N 次，不是重新表态」。是否守过由同场和上一场已读入痕迹判断；次数按本场实际守住的次数计数，跨场首次重复显示第 2 次。计数只在本场累计，不落盘。不改判定结果、不新增识别通道。

## 落痕与跨场

只有 `posture == "non_negotiable"` 且能落到结构化点时写 `kept`，按 `(kind, point)` 去重；同场最多 20 条，落盘每场最多 20 条。旧格式的 `what` 条目直接忽略，不迁移、不猜测。

## 痕迹在台上的用法（本刀）

`reasserts_kept` 为真时，`brief_to_prompt` 只多一句中文姿态：「这一条你本场已经守过，不用重新解释，短一点说完就行。」不发枚举或字段名；为假时 prompt 不变。

痕迹在本刀里是姿态输入，让同一个判定连续、不重复解释；不是识别通道。跨语义改口识别仍挂 `intent_org`／真模型意图层那一刀。

## 能力边界

stub 层不做跨语义改口识别：这是明确的能力边界，不是待修的 bug。不命中任何结构点的换说法（例如「你三岁那阵子住哪儿」）不会被判 `non_negotiable`；等 `intent_org`／真模型意图层补。靠字面相似度冒充语义等于回到词表，明确不做。

## 出处

《活出生命的意义》：守住的是真做过的取舍，不是写好的价值观。痕迹通道与持久化属外补。

## 不做

value 词表、性格描述、改 articulate 模板、改 arbitrate org 分支、动 drive 层、扩 must_not_pretend、任何字面／关键词／最长公共子串匹配。

## 验收

同场重复同一点时标记重复且去重；首次出现不标记；跨场可读；两次均走冲突路径；未命中结构点的改口明确保持能力缺口。运行指定痕迹测试及全部 birth 测试。
