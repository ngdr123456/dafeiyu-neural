# 意义层取舍痕迹（STANCE_TRACE_V1）

> 开口后的体验回流记录真正做过的取舍，供同场和下一场的立场判据读取；不是人格或价值观表。

## 出处

意义方向优先《活出生命的意义》：守住的是真做过的取舍，不是写好的价值观。同场守诺痕迹、跨场痕迹持久化，以及「换个说法再问同一个点」的匹配口径均属外补。

## 落痕与读取

开口后，`non_negotiable` 优先记录组织冲突点，否则记录同场守诺的承诺，或复用匹配到的已守痕迹，记为 `kept`。非默认 `yieldable` 的 stake 记为 `yielded`；`needs_clarify` 不落痕。记录来自结构化判据，不抄开口的句子。同场按 `(kind, what)` 去重；新场清空同场痕迹，结束时以 `stance_traces` 持久化，含 `kind`、`what`、`why`，下一场读入 prior，默认最多保留每场 20 条。

仅推问形状匹配 `kept`：读取本场及上场存储的 `what`，归一化后寻找长度至少为二且含非功能字的最长公共连续子串。冲突标签描述仅用于写入痕迹，识别用户意图仍走既有 `detect_org_conflict`，没有新增触发词表。匹配是字符级重叠，不是真正的语义模型，可能误命中或遗漏，是已知限制；没有痕迹时新判据不生效。

## 不做

不做 value 词表、性格描述、改 articulate 模板、改 arbitrate org 分支、动 drive 层、扩 must_not_pretend、关键词表冒充痕迹匹配。

## 验收

1. 同场先守住无来源经历，换说法再推仍守住，且不重复落痕。
2. 无痕迹时同一句换说法不会触发守过痕迹判据。
3. 跨场落盘后 prior 能读回 kept 痕迹。
4. 同场连续推同一冲突点只保留一条 kept 痕迹。
