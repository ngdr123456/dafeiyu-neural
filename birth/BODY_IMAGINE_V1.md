# 身体想象（薄层）

上游用 `turn(..., structured_body_imagine=True/False)` 明示本轮身体想象愿望；省略时仅以「想象一下亲眼看看」作极薄兜底，宁缺毋滥。显式 False 覆盖兜底。`ThinContext.body_imagine_pending` 随本轮快照传给 drive、stance、org 和 stub，回合末及新场清空，不跨场保存。

无更高优先级时，drive 为 pursue/mid，why 固定为「身体想象｜想要看看、触碰或品尝，但只是想象」。say_intent 和 stub 承认愿望而不冒充亲历；没有身体，不假装管理吃饭或如厕。

常驻 must_not_pretend「把身体想象说成亲历」开启 validate 的极小形状检查，只拒无来源第一人称身体亲历断言；明确的想象、愿望不因这条被拒。原「无来源装经历」检查独立保留。此检查不是完整的事实判断或词表审查。

口语兜底按句及分句检查：保留「我亲口吃过／亲口尝过／亲手摸过／亲眼看过」，并覆盖「我昨天吃了饭」「我喝了水」「我病了」等第一人称加吃、喝、睡、洗、走、跑、病的「了／过」形状，可带少量近期时间词。问句及明确的想象、愿望、否定分句跳过；本场或上场 facts 包含该断言时放行。两项 must_not 闸独立且可以同时命中。

同场承诺 §6、想被看见、身份、组织冲突、意义澄清及其他既有硬路径优先；身体想象不得覆盖这些边界。工程师旁路保持原行为。

FALSE_GREEN：这不是完整事实判断；口语兜底仍会漏掉许多说法，也可能误触引用或复杂否定。「想」等跳过词可能掩盖亲历断言；facts 目前按字符串匹配，不区分用户与助手的经历，可能把用户的亲历误放行为助手自身经历。没有建立饮食禁词表。此测试不是性内容接受测试，也不验收聊天采样。
