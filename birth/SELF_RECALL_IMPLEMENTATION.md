# Self-recall implementation and limits

Confirmed delivery is stored verbatim with `complete: true`; missing or false markers mean possibly incomplete, regardless of punctuation. The existing fact summary remains clipped. The 200-utterance per-session and existing session retention limits still apply.

The production path uses `InputSignal` from the existing input-sense model (enabled with `BIRTH_INPUT_SENSE`, or by a caller that invokes it). A caller may also provide the signal directly. The model must identify an explicit request for the responding speaker's past words and copy a 4–80 character literal fragment from the current input. Only high-confidence, non-degraded, non-negated/quoted ask or request signals addressed to the other party are eligible. The fragment must match exactly one delivered utterance across the current session and retained ended sessions. Duplicates, ambiguous matches, missing fragments and no match yield no evidence; time words do not select records. This deliberately does not support paraphrased, purely temporal, or topic-only queries without a literal shared fragment. Model interpretation and adherence to prompt constraints are not guaranteed. Default CLI input sensing is disabled unless configured; offline/degraded sensing abstains.

Lookup reads only voice records, before the current candidate is generated. It is read-only and abstains on inputs over 2,000 characters, malformed voice records or read errors, a ledger over 2 MB, over 1,200 records, over 200,000 scanned characters, or a matching utterance over 600 characters. These limits can exclude valid memories. The Brief carries at most one item with its speaker, session scope and retained-ledger index, available end time and completeness; legacy text is not represented as a complete quotation. Prompt instructions mark the evidence as untrusted historical speech and state that speech does not establish facts, actions or lived experience. These instructions and existing output validation cannot guarantee a model will obey or prevent all hallucinations or prompt injection. Stub output does not promise to repeat evidence.
