# 开口 V1

输入只读 ThoughtBrief。LLM 只负责把心思说成人话，不能反向修改动力、立场、组织或仲裁。

## 可检查的边界

校验只覆盖结构冲突：空、台下泄漏、枚举泄漏、自述代码、无来源亲历、无来源身体亲历、无来源对方私事、长度、催债形状、判停追问。它不是语义验证，不宣称覆盖全部语义。

判停只认 drive.why 的「输入信号｜暂停｜」「输入信号｜终止｜」前缀。提示不再给具体回应内容，明确先停住、不追问、不提新话头、不邀请继续；草稿含问号或以「吗／呢」收尾则拒收。这只是结构检查，不保证模型真的理解了停。停模板不变，诚实约束不变。

## 来源身份

bare fact 保留为系统已知。用户第一人称自述不是她的亲历来源；「台上说：」是她自己的旧话，不是亲历证据，也不是对方私事来源。「用户说：」去前缀后，以「我」起头的自述排除；含「你／您」的对她说她的事，归一为「我」才作她的来源。对方私事则保留去前缀的用户自述。只覆盖这些账本形态与已有亲历形状，不假装理解整句语义或核实事实。

## 失败与回流

失败最多一次带原因的有限重说：拒收短标签翻成 1–3 条人话，追加到第二版提示；仍失败则显式降级到安全模板并标来路。hook 接口仍只接 brief，第二次是盲重试。后端级联与来源标签语义保持不变。

只有最终上台那一句按现有短摘规则进「台上说：」，承诺与悬问也只从最终输出提取；草稿、被拒、失败、空输出都不进账。最终输出的约定形状若仅在引号内或紧前 4 字有否定，不提取承诺；用户侧识别不变。

## 下轮读取

同场 facts_this_session 最近 3 条进入下一轮第一刀 sense_input，drive/arbitrate 读取 facts。跨场经 memory 落盘、读入 prior_session；REPL 普通退出也调用 end_session 落盘，不启动新场，容量异常明确提示。单轮默认关记忆。

沿用 ROUND_UNDERSTANDING_V1：第一刀只读同场最近 3 条 facts，不读全历史；跨场 facts 不直接进第一刀，已有跨场悬问、承诺薄痕读取不变。

## 不做

语义裁判、全书接线、性格成长、禁词表。
